## **1. 数据预处理**
### **1.1 加载数据与初步观察**
- 检查数据字段类型、缺失值（如 `Age`、`Embarked`、`Cabin` 缺失较多）、分布情况。
- 删除无关字段：
  - `PassengerId`、`Name`、`Ticket`、`Cabin`（缺失过多）。

### **1.2 处理缺失值**
- **Age**：用中位数填充（避免异常值影响）。
- **Embarked**：用众数填充（如 `S`）。
- **Fare**：用中位数填充（若存在缺失）。

### **1.3 类别型变量编码**
- **Sex**：标签编码（`male=0, female=1`）。
- **Embarked**：独热编码（`S`, `C`, `Q` 转换为三列）。

---

## **2. 特征工程**
### **2.1 创建新特征**
- **FamilySize**：`SibSp + Parch + 1`（家庭成员总数）。
- **IsAlone**：若 `FamilySize=1` 则为 `1`，否则为 `0`。
- **AgeGroup**：将 `Age` 分箱（如 `0-12`, `13-18`, `19-55`, `56+`）。
- **FareGroup**：将 `Fare` 分箱（如按四分位数划分）。

### **2.2 特征选择**
- 保留关键特征：`Pclass`, `Sex`, `Age`, `SibSp`, `Parch`, `Fare`, `Embarked`, `FamilySize`, `IsAlone`。

---

## **3. 数据分割**
- 按比例（如 8:2 或 7:3）将数据分为训练集和测试集。

---

## **4. 模型训练**
- 初始化决策树分类器：
  ```python
  from sklearn.tree import DecisionTreeClassifier
  clf = DecisionTreeClassifier(random_state=42)
  ```

---

## **5. 模型评估**
- 使用交叉验证计算准确率、精确率、召回率、F1 分数。
- 生成混淆矩阵和分类报告：
  ```python
  from sklearn.metrics import classification_report, confusion_matrix
  ```

---

## **6. 参数调优（优化步骤）**
### **6.1 网格搜索（GridSearchCV）**
- 调整关键参数防止过拟合：
  ```python
  param_grid = {
      'max_depth': [3, 5, 7, 10],
      'min_samples_split': [2, 5, 10],
      'min_samples_leaf': [1, 2, 4],
      'criterion': ['gini', 'entropy']
  }
  ```
- 使用交叉验证选择最优参数。

### **6.2 剪枝策略**
- 设置 `ccp_alpha` 进行代价复杂度剪枝，平衡模型复杂度与准确率。

---

## **7. 特征重要性分析**
- 查看 `clf.feature_importances_`，筛选重要性高的特征（如 `Sex`、`Pclass` 可能关键）。

---

## **8. 处理类别不平衡**
- 若幸存者比例不均，设置 `class_weight='balanced'` 或使用过采样（如 SMOTE）。

---

## **9. 最终模型验证**
- 用测试集评估调优后的模型，确保泛化能力。

---

## **10. 可视化决策树（可选）**
- 使用 `graphviz` 或 `plot_tree` 可视化树结构，辅助解释模型逻辑。

---

## **优化总结**
1. **参数调优**：通过网格搜索优化 `max_depth`、`min_samples_split` 等。
2. **特征工程**：构造 `FamilySize`、`IsAlone` 等衍生特征提升信息量。
3. **处理缺失与异常**：合理填充缺失值，避免噪声影响。
4. **剪枝与正则化**：控制模型复杂度，防止过拟合。
5. **类别平衡**：调整样本权重或重采样，解决数据不平衡问题。

## **示例代码框架**

```python
# -*-coding: utf-8 -*-
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.tree import DecisionTreeClassifier, plot_tree
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix
from sklearn.preprocessing import OneHotEncoder
from sklearn.compose import ColumnTransformer
import matplotlib.pyplot as plt
from matplotlib import rcParams

# 配置 matplotlib 使用字体
rcParams['font.sans-serif'] = ['Heiti TC']
rcParams['axes.unicode_minus'] = False  # 解决负号显示问题


def preprocess_data(data, is_train=True):
    # 为训练数据和测试数据分别处理
    if is_train:
        # 删除无关列
        data = data.drop(["PassengerId", "Ticket", "Cabin"], axis=1)
    else:
        # 测试数据需要保留 PassengerId
        data = data.drop(["Ticket", "Cabin"], axis=1)
    
    # 处理缺失值
    data["Age"] = data["Age"].fillna(data["Age"].median())  # 年龄用中位数填充
    data["Embarked"] = data["Embarked"].fillna(data["Embarked"].mode()[0])  # 登船港口用众数填充
    data["Fare"] = data["Fare"].fillna(data["Fare"].median())  # 票价用中位数填充
    
    # 特征工程
    data["FamilySize"] = data["SibSp"] + data["Parch"] + 1
    data["IsAlone"] = (data["FamilySize"] == 1).astype(int)
    
    # 提取姓名中的头衔
    data["Title"] = data["Name"].str.extract(r' ([A-Za-z]+)\.', expand=False)
    data["Title"] = data["Title"].replace(['Lady', 'Countess', 'Capt', 'Col', 'Don', 'Dr', 'Major', 'Rev', 'Sir', 'Jonkheer', 'Dona'], 'Rare')
    data["Title"] = data["Title"].replace('Mlle', 'Miss')
    data["Title"] = data["Title"].replace('Ms', 'Miss')
    data["Title"] = data["Title"].replace('Mme', 'Mrs')
    
    # 年龄分段
    data["AgeBand"] = pd.cut(data["Age"], bins=[0, 12, 18, 30, 50, 100], labels=['Child', 'Teenager', 'YoungAdult', 'Adult', 'Senior'])
    
    # 删除原始列
    data = data.drop(["Name", "Age"], axis=1)
    
    return data


def main():
    # 1. 加载数据
    train_data = pd.read_csv("train.csv")
    test_data = pd.read_csv("test.csv")
    
    # 2. 数据预处理
    train_data = preprocess_data(train_data, is_train=True)
    test_data = preprocess_data(test_data, is_train=False)
    
    # 3. 类别型变量编码
    preprocessor = ColumnTransformer(
        transformers=[
            ("onehot", OneHotEncoder(drop="first"), ["Sex", "Embarked", "Title", "AgeBand"])
        ],
        remainder="passthrough"
    )
    
    # 分割特征与标签
    X_train = train_data.drop("Survived", axis=1)
    y_train = train_data["Survived"]
    X_test = test_data.drop("PassengerId", axis=1)  # 测试数据中保留 PassengerId
    
    # 应用预处理
    X_train_processed = preprocessor.fit_transform(X_train)
    X_test_processed = preprocessor.transform(X_test)
    
    # 4. 数据分割
    X_train_split, X_val, y_train_split, y_val = train_test_split(
        X_train_processed, y_train, test_size=0.2, random_state=42
    )
    
    # 5. 模型训练与调优
    clf = DecisionTreeClassifier(random_state=42)
    
    # 定义参数网格
    param_grid = {
        "max_depth": [3, 5, 7, 9, None],
        "min_samples_split": [2, 5, 10, 20],
        "min_samples_leaf": [1, 2, 4, 8],
        "criterion": ["gini", "entropy"],
        "class_weight": [None, "balanced"]
    }
    
    # 网格搜索
    grid_search = GridSearchCV(clf, param_grid, cv=5, scoring="accuracy", n_jobs=-1)
    grid_search.fit(X_train_split, y_train_split)
    
    # 获取最优模型
    best_clf = grid_search.best_estimator_
    print("最佳参数:", grid_search.best_params_)
    
    # 6. 模型评估
    y_pred = best_clf.predict(X_val)
    print("\n验证集准确率:", accuracy_score(y_val, y_pred))
    print("\n分类报告:")
    print(classification_report(y_val, y_pred))
    print("\n混淆矩阵:")
    print(confusion_matrix(y_val, y_pred))
    
    # 7. 特征重要性分析
    feature_names = preprocessor.get_feature_names_out()
    feature_importance = pd.DataFrame({
        "Feature": feature_names,
        "Importance": best_clf.feature_importances_
    }).sort_values("Importance", ascending=False)
    
    print("\n特征重要性:")
    print(feature_importance)
    
    # 8. 可视化决策树（可选）
    plt.figure(figsize=(20, 10))
    plot_tree(
        best_clf,
        feature_names=feature_names,
        class_names=["Died", "Survived"],
        filled=True,
        rounded=True,
        max_depth=3  # 限制深度以便查看
    )
    plt.title("决策树结构（前3层）")
    plt.show()
    
    # 9. 测试集预测
    test_pred = best_clf.predict(X_test_processed)
    # 创建提交文件
    submission = pd.DataFrame({
        "PassengerId": test_data["PassengerId"],
        "Survived": test_pred
    })
    submission.to_csv("gender_submission.csv", index=False)
    print("\n测试集预测结果已保存到 gender_submission.csv")


if __name__ == "__main__":
    main()
```
