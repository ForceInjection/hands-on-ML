# 数据准备与数据处理 - 以 Titanic 生存预测为例

数据准备与处理是机器学习项目中至关重要的一环，高质量的数据是构建高性能模型的基础。本文档将结合经典的 **Titanic 生存预测** 案例，系统梳理从数据理解到特征工程的完整流程。

> **案例来源**：本项目中的 `titanic/titanicgrissom.ipynb` 代码示例。

## 1. 建模流程回顾

机器学习项目的建模流程通常是一个迭代的闭环过程（CRISP-DM），主要包含以下核心阶段：

1. **业务理解**：明确 Titanic 任务目标——根据乘客信息预测其是否获救（二分类问题）。
2. **数据理解**：收集原始数据，进行初步探索，了解特征含义及分布。
3. **数据准备**：清洗数据（处理缺失值、异常值），进行特征工程（构造新特征、编码），构建最终的训练集。
4. **模型建立**：选择分类算法（如随机森林、逻辑回归等）进行训练。
5. **模型评估**：使用准确率（Accuracy）、混淆矩阵等指标评估模型效果。
6. **部署**：将模型应用于实际预测。

## 5. 数据预处理

数据预处理是将原始数据转换为适合模型训练格式的关键步骤。

### 5.1 缺失值处理

根据数据的特点选择合适的填充策略：

- **Age (年龄)**：年龄与客舱等级（Pclass）和称谓（Title）相关，因此采用分组中位数填充。
- **Embarked (登船口)**：缺失很少，用众数（Mode）填充。
- **Fare (票价)**：缺失很少，用中位数（Median）填充。
- **Cabin (客舱号)**：缺失严重，提取其首字母作为甲板号（Deck），缺失值标记为 'U' (Unknown)。

```python
# 1. Age: 使用 Pclass 和 Title 分组后的中位数填充
# (假设 Title 特征已提取，见下文特征工程)
data['Age'] = data.groupby(['Pclass', 'Title'])['Age'].transform(lambda x: x.fillna(x.median()))

# 2. Embarked: 使用众数填充
data['Embarked'] = data['Embarked'].fillna(data['Embarked'].mode()[0])

# 3. Fare: 使用中位数填充
data['Fare'] = data['Fare'].fillna(data['Fare'].median())

# 4. Cabin: 转换为是否有客舱，或提取甲板号
data['Has_Cabin'] = data['Cabin'].notnull().astype(int)
data['Cabin_Deck'] = data['Cabin'].str[0].fillna('U')
```

### 5.2 数据清洗

删除对预测没有明显帮助或缺失过多的列。

```python
# 删除 Ticket 和 Cabin (已提取信息后)
drop_cols = ["Ticket", "Cabin", "PassengerId"]
data = data.drop(drop_cols, axis=1)
```

## 6. 特征变量的构造和组合

通过特征工程挖掘数据中的隐藏信息。

### 6.1 特征构造

- **Title (称谓)**：从姓名中提取称谓（如 Mr, Mrs, Miss, Master），反映社会地位和性别年龄信息。（注：该特征已在 5.1 节缺失值处理中提取，此处主要展示构造逻辑）。
- **FamilySize (家庭规模)**：结合 `SibSp` 和 `Parch` 计算家庭总人数。
- **IsAlone (是否独行)**：标记是否独自一人乘船。

```python
# 1. 提取 Title (如果在预处理阶段未执行，需在此执行)
# data["Title"] = data["Name"].str.extract(r' ([A-Za-z]+)\.', expand=False)
# ... (映射逻辑同上)

# 2. 构造 FamilySize 和 IsAlone
data['FamilySize'] = data['SibSp'] + data['Parch'] + 1
data['IsAlone'] = (data['FamilySize'] == 1).astype(int)

# 删除原始 Name 列
data = data.drop(["Name"], axis=1)
```

### 6.2 特征分箱

将连续数值特征转换为离散的区间特征，增强模型的鲁棒性。

```python
# Age 分箱
data['AgeBin'] = pd.cut(data['Age'], bins=[0, 12, 18, 30, 50, 100],
                        labels=['Child','Teenager','YoungAdult','Adult','Senior'])

# Fare 分箱
data['FareBin'] = pd.cut(data['Fare'], bins=[0, 10, 30, 100, 250, 600], labels=False)
```

### 6.3 特征编码

将类别型特征转换为数值型，以便模型处理。常用 **One-Hot Encoding**。

```python
# 定义需要编码的特征
categorical_features = ['Pclass', 'Sex', 'Embarked', 'Title', 'AgeBin']

# 使用 Pandas 的 get_dummies 进行独热编码
data_encoded = pd.get_dummies(data, columns=categorical_features, drop_first=True)

print(data_encoded.head())
```

> **Scikit-Learn Pipeline 方式**：
> 在实际工程中，推荐使用 `ColumnTransformer` 和 `Pipeline` 来封装预处理步骤，防止训练集和测试集处理不一致（Data Leakage）。

```python
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.compose import ColumnTransformer

# 定义预处理管道
preprocessor = ColumnTransformer(
    transformers=[
        ("cat", OneHotEncoder(drop="first"), ["Sex", "Embarked", "Title", "AgeBin"]),
        ("num", StandardScaler(), ["Fare", "FamilySize"]),
        ("passthrough", "passthrough", ["IsAlone", "Pclass"]) # 已经是数值的特征
    ]
)
```

## 7. 总结

数据准备与处理是连接原始数据与机器学习模型的桥梁。通过 Titanic 案例，我们实践了以下核心步骤：

1. **数据探索（EDA）**：通过单变量和多变量分析，发现了“女士优先”、“富人优先”以及“儿童生存率高”等关键规律。
2. **数据清洗**：针对不同特征的缺失情况（如 Age, Cabin），采用了基于业务逻辑的填充策略（如分组中位数填充）。
3. **特征工程**：
   - **构造**：从姓名中提取了 `Title`，从家庭关系中构造了 `FamilySize` 和 `IsAlone`。
   - **分箱**：将 `Age` 和 `Fare` 离散化，提升了模型的泛化能力。
   - **编码**：将类别特征转换为数值编码（One-Hot），使其适配大多数机器学习算法。

高质量的特征工程往往能带来比单纯的模型调优更大的性能提升。在实际应用中，建议使用 `Pipeline` 将这些步骤标准化，以确保模型上线后的稳定性和可维护性。
