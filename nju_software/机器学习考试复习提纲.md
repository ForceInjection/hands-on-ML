# 机器学习考试复习提纲

## 第一章 机器学习基础概念

### 1.1 人工智能与机器学习关系

- **人工智能概念**：最早由图灵于1950年提出，并提出图灵测试模型
- **关系层次**：人工智能 > 机器学习 > 深度学习
- **误区澄清**：人工智能≠深度学习，机器学习是人工智能的实现手段
- **应用领域**：机器翻译、人脸识别、指纹识别等（VR不属于AI范畴）

### 1.2 机器学习基本概念

- **定义与特点**：可解决图像识别等问题，依赖统计学习
- **局限性**：目前无法完全代替人类
- **主要分类**：监督学习、无监督学习、强化学习

### 1.3 任务分类详解

#### 1.3.1 监督学习

- **定义**：使用有标签的训练数据进行学习
- **典型算法**：决策树、朴素贝叶斯、SVM、逻辑回归、KNN
- **应用场景**：分类（垃圾邮件检测）、回归（房价预测）

#### 1.3.2 无监督学习

- **定义**：从无标签数据中发现隐藏模式
- **典型算法**：K-means、DBSCAN、PCA、GMM
- **应用场景**：聚类、降维、异常检测

#### 1.3.3 强化学习

- **定义**：通过与环境交互获得奖励信号进行学习
- **核心要素**：状态、动作、奖励、策略
- **应用场景**：游戏AI、机器人控制、推荐系统

### 1.4 问题类型识别

- **分类问题**：预测离散标签（二分类/多分类）
- **回归问题**：预测连续数值
- **聚类问题**：将相似样本分组
- **关联规则挖掘**：发现数据项之间的关联关系

## 第二章 数据预处理与特征工程

### 2.1 数据预处理流程

1. **数据获取**：从数据库、文件、API等获取原始数据
2. **数据探索**：了解数据分布、特征类型、数据量等基本信息
3. **数据清洗**：处理缺失值、异常值、重复值、数据类型转换
4. **特征工程**：特征选择、特征提取、特征构造、特征变换
5. **数据标准化/归一化**：将不同量纲和数值范围的特征统一转换到相同尺度（如[0,1]区间或标准正态分布），避免数值范围大的特征主导模型训练。
6. **数据分割**：训练集/验证集/测试集

### 2.2 特征处理

#### 2.2.1 数值特征处理

- **Min-Max缩放**：
  - 公式：$x_{scaled} = \frac{x - x_{min}}{x_{max} - x_{min}}$
  - 映射到[0,1]区间
  - 保持原始分布形状
  - **计算例子**：
    - 属性income：最小值12000，最大值98000
    - 73600的归一化结果：$\frac{73600-12000}{98000-12000} = \frac{61600}{86000} = 0.716$

- **标准化（Z-score标准化）**：
  - 公式：$x_{std} = \frac{x - \mu}{\sigma}$
  - 均值0，方差1
  - 适用于正态分布数据

- **最小-最大规范化到指定区间**：
  - 公式：$x_{new} = \frac{(x - x_{min}) \times (new_{max} - new_{min})}{x_{max} - x_{min}} + new_{min}$

- **计算例子**：
  - 数据组：200,300,500,700,1000
  - 规约到区间[5,10]，数据500的变换：
    - $x_{new} = \frac{(500-200) \times (10-5)}{1000-200} + 5 = \frac{300 \times 5}{800} + 5 = 6.875$
    - **说明**：
      - 数据最小值：200
      - 数据最大值：1000
      - 数据范围：1000-200 = 800
      - 目标区间：[5,10]，范围为10-5 = 5

- **需要处理的算法**：逻辑回归、SVM、KNN、神经网络
- **不需要处理的算法**：决策树、随机森林、GBDT

- **特征分箱**：
  - 等宽分箱：$width = \frac{x_{max} - x_{min}}{n}$
  - 等频分箱：每箱样本数相等，每箱样本数 = 总样本数 / 箱数；
  - 卡方分箱：基于卡方统计量

- **计算例子**：
  - 数据：5, 10, 11, 13, 15, 35, 50, 55, 72, 92, 204, 215
  - **a) 等宽划分四个箱子**：
    - 最小值：$\min = 5$
    - 最大值：$\max = 215$
    - 数据范围：$\text{range} = 215 - 5 = 210$
    - 箱子宽度：$\text{width} = \frac{210}{4} = 52.5$
    - **4个箱子的划分**：
      - 箱子1：$[5, 57.5)$ → 包含数据：5, 10, 11, 13, 15, 35, 50, 55
      - 箱子2：$[57.5, 110)$ → 包含数据：72, 92
      - 箱子3：$[110, 162.5)$ → 包含数据：无
      - 箱子4：$[162.5, 215]$ → 包含数据：204, 215
  - **b) 等频划分四个箱子**：
    - 数据总数：$n = 12$
    - 每个箱子的数据个数：$\frac{12}{4} = 3$
    - 按数值排序后，每3个数据分为一组
    - **4个箱子的划分**：
      - **箱子1**：$[5, 11]$ → 包含数据：5, 10, 11
      - **箱子2**：$(11, 35]$ → 包含数据：13, 15, 35  
      - **箱子3**：$(35, 72]$ → 包含数据：50, 55, 72
      - **箱子4**：$(72, 215]$ → 包含数据：92, 204, 215

#### 2.2.2 类别特征处理

- **One-Hot编码**：
  - 适用于：颜色、品牌等无序类别特征
  - 不适用于：年龄等数值特征
  - 问题：高维稀疏、多重共线性
- **标签编码**：将类别映射为数字
- **目标编码**：用目标变量的统计量编码
- **二进制编码**：减少One-Hot编码的维度

#### 2.2.3 时间特征处理

- **时间格式转换**
  - **提取日期元素**：年、月、日、季度、星期等
  - **时间差特征**：距离某个重要时间点的天数
  - **周期性特征**：sin/cos变换处理周期性

### 2.3 距离度量

- **欧几里得距离**：$d = \sqrt{\sum_{i=1}^{n} (x_i - y_i)^2}$
- **曼哈顿距离**：$d = \sum_{i=1}^{n} |x_i - y_i|$
  - **计算例子**：
    - 点A(2,-2)到B(-1,2)的曼哈顿距离：
    - $d = |2-(-1)| + |-2-2| = |3| + |-4| = 3 + 4 = 7$

- **余弦相似度**：$\cos(\theta) = \frac{A \cdot B}{||A|| \times ||B||}$
  - **计算例子**：
    - 向量a=[1,2]，向量b=[4,5]
    - $A \cdot B = 1 \times 4 + 2 \times 5 = 14$
    - $||A|| = \sqrt{1^2 + 2^2} = \sqrt{5}$
    - $||B|| = \sqrt{4^2 + 5^2} = \sqrt{41}$
    - $\cos(\theta) = \frac{14}{\sqrt{5} \times \sqrt{41}} = \frac{14}{\sqrt{205}} \approx 0.978$

- **向量范数**：
  - L1范数：$||x||_1 = \sum_{i=1}^{n} |x_i|$
  - L2范数：$||x||_2 = \sqrt{\sum_{i=1}^{n} x_i^2}$
  - L∞范数：$||x||_{\infty} = \max_i |x_i|$
  - **计算例子**：
    - 向量 A = [1, 3, 6, 4, -9, 0]
    - L1范数：$|1| + |3| + |6| + |4| + |-9| + |0| = 1 + 3 + 6 + 4 + 9 + 0 = 23$
    - L2范数：$\sqrt{1^2 + 3^2 + 6^2 + 4^2 + (-9)^2 + 0^2} = \sqrt{116} \approx 10.54$
    - L∞范数：$\max(|1|, |3|, |6|, |4|, |-9|, |0|) = \max(1, 3, 6, 4, 9, 0) = 9$

### 2.4 特征选择

- **过滤法（Filter）**：
  - 方差选择法：移除低方差特征
  - 相关系数法：移除高相关特征
  - 卡方检验：适用于分类问题
  - 互信息：衡量特征与目标的相关性
- **包装法（Wrapper）**：
  - 递归特征消除（RFE）
  - 前向选择、后向消除
- **嵌入法（Embedded）**：
  - L1正则化（Lasso）
  - 基于树的特征重要性

## 第三章 贝叶斯理论基础

### 3.1 贝叶斯定理

- **公式**：$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$
- **组成部分**：
  - $P(A|B)$：后验概率
  - $P(B|A)$：似然
  - $P(A)$：先验概率
  - $P(B)$：边际概率
- **应用场景**：医疗诊断、车祸责任判定、产品质检、垃圾邮件过滤

### 3.2 实际计算案例

#### 3.2.1 医疗诊断案例

- **问题设置**：
  - 疾病患病率：$P(D) = 0.01$
  - 检测敏感性：$P(+|D) = 0.95$
  - 检测特异性：$P(-|\neg D) = 0.95$
- **计算检测阳性时患病概率**：
  - $P(+) = P(+|D)P(D) + P(+|\neg D)P(\neg D)$
  - $P(+) = 0.95 \times 0.01 + 0.05 \times 0.99 = 0.0095 + 0.0495 = 0.059$
  - $P(D|+) = \frac{P(+|D)P(D)}{P(+)} = \frac{0.95 \times 0.01}{0.059} = \frac{0.0095}{0.059} \approx 0.161$

#### 3.2.2 质量检测案例

- **问题设置**：
  - 合格品率：$P(G) = 0.95$（G表示合格品Good）
  - 不合格品率：$P(B) = 0.05$（B表示不合格品Bad）
  - 检测准确率：$P(Pass|G) = 0.98$（合格品检测通过的概率）
  - 检测准确率：$P(Fail|B) = 0.99$（不合格品检测不通过的概率）
  - 因此：$P(Pass|B) = 1 - P(Fail|B) = 0.01$（不合格品检测通过的概率）
- **计算检测通过时产品合格的概率**：
  - $P(Pass) = P(Pass|G)P(G) + P(Pass|B)P(B)$
  - $P(Pass) = 0.98 \times 0.95 + 0.01 \times 0.05 = 0.931 + 0.0005 = 0.9315$
  - $P(G|Pass) = \frac{P(Pass|G)P(G)}{P(Pass)} = \frac{0.98 \times 0.95}{0.9315} = \frac{0.931}{0.9315} \approx 0.9995$

### 3.3 贝叶斯网络

- **定义**：有向无环图表示变量间的条件依赖关系
- **推理**：精确推理、近似推理
- **学习**：参数学习、结构学习

## 第四章 监督学习

### 4.1 监督学习概述

- **定义**：有标签数据的学习方式
- **分类问题 vs 回归问题**
  - 分类：预测离散标签（如垃圾邮件检测、癌症诊断）
  - 回归：预测连续数值（如房价预测、点击量预测）

### 4.2 分类算法

#### 4.2.1 决策树

- **算法类型**：ID3、C4.5、CART
- **核心概念**：
  - 信息熵：$H(X) = -\sum_{i=1}^{n} p(x_i)\log_2(p(x_i))$
  - 信息增益：$IG(D,A) = H(D) - \sum_{v} \frac{|D^v|}{|D|} H(D^v)$
  - 信息增益率：$IGR(D,A) = \frac{IG(D,A)}{IV(A)}$，其中 $IV(A) = -\sum_{v} \frac{|D^v|}{|D|} \log_2 \frac{|D^v|}{|D|}$
  - 基尼指数：$Gini(D) = 1 - \sum_{k=1}^{|y|} p_k^2$
  - **计算例子**：
    - 变量 [0,0,1,1,1] 的信息熵计算：
      - $p(0) = \frac{2}{5}$，$p(1) = \frac{3}{5}$
    - $H = -(\frac{3}{5} \log_2(\frac{3}{5}) + \frac{2}{5} \log_2(\frac{2}{5}))$
- **特点**：
  - ID3：只能处理分类问题，使用信息增益
  - C4.5：改进的ID3，可处理连续特征，使用信息增益率
  - CART：既可分类又可回归，使用基尼指数
- **父子节点关系**：一般情况下父节点熵更大（分割后不确定性降低）

#### 4.2.2 朴素贝叶斯

- **核心假设**：特征条件独立
- **贝叶斯定理应用**：$P(C|X) = \frac{P(X|C)P(C)}{P(X)}$
- **优缺点**：
  - 优点：算法简单，时空开销小，对缺失数据不敏感
  - 缺点：强独立性假设在实际中往往不成立
- **适用场景**：文本分类、垃圾邮件过滤

#### 4.2.3 逻辑回归

> 注意：逻辑回归是一种广义线性模型，可解决二分类问题，不是用于解决回归问题。

- **本质**：线性分类器，使用Sigmoid函数
- **Sigmoid函数**：$\sigma(z) = \frac{1}{1+e^{-z}}$
- **特点**：
  - 可解决二分类问题，也可扩展到多分类（One-vs-Rest）
  - 属于广义线性回归
- **多分类策略**：对于n类分类，需训练n个模型
- **优势**：输出概率值，可解释性强

#### 4.2.4 支持向量机（SVM）

- **核心思想**：寻找最优分离超平面，最大化间隔
- **核函数**：可与核函数结合处理非线性问题
  - 线性核：$K(x,y) = x^T \cdot y$
  - 多项式核：$K(x,y) = (x^T \cdot y + c)^d$
  - RBF核：$K(x,y) = \exp(-\gamma||x-y||^2)$
- **优缺点**：
  - 优点：泛化能力好，可结合核函数，调参效果好
  - 缺点：训练速度较慢，对大规模数据不友好
- **支持向量**：训练完成后只需保存支持向量即可分类

#### 4.2.5 K 近邻算法（KNN）

- **原理**：基于相似性进行分类
- **特点**：
  - 需保存所有训练样本（惰性学习）
  - 预测时需计算与所有训练样本的距离（线性搜索）
  - kdtree可优化搜索效率
- **距离度量**：欧几里得距离、曼哈顿距离、余弦距离
- **参数选择**：k值的选择影响模型复杂度

### 4.3 回归算法

#### 4.3.1 线性回归

- **模型形式**：$y = w_0 + w_1x_1 + w_2x_2 + \ldots + w_nx_n$
- **参数估计**：如单特征房价预测需要2个参数（斜率+截距）
- **求解方法**：
  - 最小二乘法：$\hat{w} = (X^TX)^{-1}X^Ty$，解析解，无局部最优问题
  - 梯度下降法：$w := w - \alpha \nabla J(w)$，需要设置学习率参数
- **假设条件**：线性关系、独立性、同方差性、正态性

#### 4.3.2 正则化回归

- **Ridge回归（岭回归，L2正则化）**：
  - 损失函数：$J(w) = MSE + \lambda \sum_{i=1}^{n} w_i^2$
  - 特点：不适用于特征选择，参数趋向于0但不为0
  - 主要用途：处理多重共线性问题
- **Lasso回归（L1正则化）**：
  - 损失函数：$J(w) = MSE + \lambda \sum_{i=1}^{n} |w_i|$
  - 特点：适用于特征选择，可使部分参数为0
- **Elastic Net**：结合L1和L2正则化，可用于特征选择和稀疏性

### 4.4 模型评估

#### 4.4.1 分类问题评估

- **混淆矩阵**：TP、FP、TN、FN
- **评估指标**：
  - **准确率（Accuracy）**：$Accuracy = \frac{TP+TN}{TP+TN+FP+FN}$
  - **精确率（Precision）**：$Precision = \frac{TP}{TP+FP}$
  - **召回率（Recall）**：$Recall = \frac{TP}{TP+FN}$
  - **F1值**：$F1 = \frac{2 \times Precision \times Recall}{Precision + Recall}$
  - **特异性**：$Specificity = \frac{TN}{TN+FP}$
  - **计算例子**：
    - 数据集：正样本100个，负样本100个
    - 模型预测：预测为正样本80个（其中真正样本60个）
    - 混淆矩阵：TP=60, FP=20, FN=40, TN=80
    - 召回率计算：$Recall = \frac{60}{100} = 60\%$
    - 精确率计算：$Precision = \frac{60}{80} = 75\%$
    - F1值计算：$F1 = \frac{2 \times 0.6 \times 0.75}{0.6 + 0.75} = \frac{0.9}{1.35} = 66.7\%$
    - 准确率计算：$Accuracy = \frac{60+80}{200} = 70\%$
  - **ROC曲线与AUC**：
    - ROC：FPR与TPR的关系曲线
    - AUC：ROC曲线下面积，取值范围[0,1]
    - AUC=0.5表示随机分类器

**阈值调整影响**：

- **单调性假设**：
  - 当阈值从 $\theta_1$ 提高到 $\theta_2$（其中 $\theta_2 > \theta_1$）时，存在重要的**单调性条件**：对于任意样本 $i$，若 $P(y=1|x_i) \leq \theta_1$，则必有 $P(y=1|x_i) \leq \theta_2$
  - 这保证了预测变化的单向性：
    - **允许的转换**：正类 → 负类，负类 → 负类
    - **禁止的转换**：负类 → 正类
- **变化方向的数学保证**：基于单调性，当阈值提高时，只能发生以下转换：
  - $k_1$ 个假正例转为真负例：$\text{FP} \rightarrow \text{TN}$
  - $k_2$ 个真正例转为假负例：$\text{TP} \rightarrow \text{FN}$
  - 其中 $k_1, k_2 \geq 0$

**混淆矩阵变化**：

设原始阈值下的混淆矩阵为：$\text{TP}_0, \text{FP}_0, \text{TN}_0, \text{FN}_0$

阈值提高后的变化：

$$
\begin{align}
\text{TP}_{\text{new}} &= \text{TP}_0 - k_2\\
\text{FP}_{\text{new}} &= \text{FP}_0 - k_1\\
\text{TN}_{\text{new}} &= \text{TN}_0 + k_1\\
\text{FN}_{\text{new}} &= \text{FN}_0 + k_2
\end{align}
$$

**说明**：只有原本被误分为正类的负样本（FP）会转为正确的负类预测（TN），而原本正确预测的正样本（TP）转为错误的负类预测（FN）。

**召回率变化分析**：

$$\text{Recall}_0 = \frac{\text{TP}_0}{\text{TP}_0 + \text{FN}_0}$$

$$\text{Recall}_{\text{new}} = \frac{\text{TP}_0 - k_2}{\text{TP}_0 + \text{FN}_0 + k_2}$$

**变化量**：

$$\Delta \text{Recall} = \frac{\text{TP}_0 - k_2}{\text{TP}_0 + \text{FN}_0 + k_2} - \frac{\text{TP}_0}{\text{TP}_0 + \text{FN}_0} = \frac{-k_2(\text{TP}_0 + \text{FN}_0 + k_2)}{(\text{TP}_0 + \text{FN}_0)(\text{TP}_0 + \text{FN}_0 + k_2)} \leq 0$$

由于 $k_2 \geq 0$，召回率必然**降低或不变**。

**准确率变化分析**：

$\text{Accuracy}_0 = \frac{\text{TP}_0 + \text{TN}_0}{N}$

$\text{Accuracy}_{\text{new}} = \frac{(\text{TP}_0 - k_2) + (\text{TN}_0 + k_1)}{N} = \frac{\text{TP}_0 + \text{TN}_0 + k_1 - k_2}{N}$

**变化量**：
$\Delta \text{Accuracy} = \frac{k_1 - k_2}{N}$

由于 $k_1, k_2 \geq 0$ 但 $k_1 - k_2$ 符号不确定，准确率变化方向**无法确定**。

#### 4.4.2 回归问题评估

- **MSE（均方误差）**：$MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$，越小越好
- **MAE（平均绝对误差）**：$MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$，越小越好，对异常值不敏感
- **RMSE均方根误差）**：$RMSE = \sqrt{MSE}$，越小越好，对异常值敏感
- **R²（决定系数）**：$R^2 = 1 - \frac{SS_{res}}{SS_{tot}}$，越大越好，取值范围(-∞,1]
- **MAPE（平均绝对百分比误差）**：$MAPE = \frac{1}{n} \sum_{i=1}^{n} \left|\frac{y_i - \hat{y}_i}{y_i}\right| \times 100\%$

## 第五章 无监督学习

### 5.1 聚类算法

#### 5.1.1 K-means算法

- **基本流程**：
  1. 指定聚类数k
  2. 随机选择初始聚类中心
  3. 分配样本到最近聚类中心
  4. 更新聚类中心：$\mu_k = \frac{1}{|C_k|} \sum_{x \in C_k} x$
  5. 重复直至收敛
- **目标函数**：$J = \sum_{k=1}^{K} \sum_{x \in C_k} ||x - \mu_k||^2$
- **特点**：
  - 无法自动确定聚类数量
  - 随机初始化导致结果可能不同
  - 适用于凸样本集
  - 对异常值敏感
- **评估指标**：SSE、轮廓系数、DB指数
- **优化方法**：K-means++初始化、肘部法则选择k值

#### 5.1.2 DBSCAN算法

- **特点**：基于密度的聚类，适用于非凸样本集
- **核心概念**：
  - 核心点：邻域内点数≥MinPts
  - 边界点：非核心点但在核心点邻域内
  - 噪声点：既非核心点也非边界点
- **参数**：ε（邻域半径）、MinPts（最小点数）
- **优势**：能发现任意形状的聚类，自动识别噪声点

#### 5.1.3 高斯混合模型（GMM）

- **基本思想**：假设数据由多个高斯分布混合而成
- **模型参数**：均值μ、协方差Σ、混合系数π
- **概率密度函数**：$p(x) = \sum_{k=1}^{K} \pi_k \mathcal{N}(x|\mu_k, \Sigma_k)$
- **EM算法**：
  - E步：计算后验概率 $\gamma_{nk} = \frac{\pi_k \mathcal{N}(x_n|\mu_k, \Sigma_k)}{\sum_{j=1}^{K} \pi_j \mathcal{N}(x_n|\mu_j, \Sigma_j)}$
  - M步：更新参数
- **与K-means对比**：
  - GMM：软聚类，给出概率
  - K-means：硬聚类，给出确定分配
- **优势**：可处理椭圆形聚类，提供不确定性度量

### 5.2 降维算法

#### 5.2.1 主成分分析（PCA）

- **目的**：降维、数据可视化、去噪
- **核心思想**：寻找数据方差最大的方向
- **数学原理**：
  - 协方差矩阵：$C = \frac{1}{n-1} X^T X$
  - 特征值分解：$C = Q\Lambda Q^T$
  - 主成分：特征向量对应的方向
- **特点**：
  - 无监督算法
  - 线性变换
  - 选择最大方差的主成分
  - 使用前需要标准化数据
- **应用**：等价于重建后均方误差最小
- **主成分选择**：累计方差贡献率≥85%

#### 5.2.2 线性判别分析（LDA）

- **目的**：有监督降维，最大化类间距离，最小化类内距离
- **目标函数**：$J(w) = \frac{w^T S_B w}{w^T S_W w}$
- **与PCA区别**：
  - PCA：无监督，最大化方差
  - LDA：有监督，最大化类别可分性

## 第六章 集成学习

### 6.1 Bagging方法

- **基本思想**：并行训练多个模型，投票决策
- **随机森林**：
  - 基于决策树的 Bagging
  - **基学习器类型**：可以是分类树或回归树
  - **训练方式**：并行训练，树之间相互独立
  - **多样性来源**：
    - 样本扰动：Bootstrap采样（数据样本扰动实现多样性）
    - 属性扰动：随机特征子集选择
  - **异常值处理**：通过多数投票/平均降低异常值影响，对异常值不敏感
  - **特征归一化**：不需要，基于树的分裂与特征尺度无关
  - 可用于分类和回归
- **特点**：减少方差，防止过拟合

### 6.2 Boosting方法

- **基本思想**：顺序训练，后续模型关注前面模型的错误
- **核心特点**：
  - 串行训练（非并行），模型间存在依赖关系
  - 减少偏差（vs Bagging减少方差）
  - 对异常值敏感（逐步放大异常值影响）

- **AdaBoost**：
  - 弱分类器的线性组合：$H(x) = \text{sign}\left(\sum_{t=1}^{T} \alpha_t h_t(x)\right)$
  - 权重更新：$\alpha_t = \frac{1}{2} \ln\left(\frac{1-\epsilon_t}{\epsilon_t}\right)$
  - 样本权重更新：$D_{t+1}(i) = \frac{D_t(i)}{Z_t} \exp(-\alpha_t y_i h_t(x_i))$
  - 前向分步算法实现
  - 指数损失函数
  - 顺序训练（非独立训练）
  - **注意**：弱分类器是顺序依赖训练，非独立并行

- **GBDT（梯度提升决策树）**：
  - 只使用回归树（即使分类问题也用回归树输出概率）
  - 对异常值敏感
  - 顺序训练
  - 拟合残差：$r_{mi} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$
  - 不需要特征归一化

- **XGBoost**：GBDT的优化版本
  - 支持并行计算（单棵树内部并行，非树间并行）
  - 正则化项
  - 处理缺失值
  - 支持特征重要性筛选
  - 可配置随机特征子集（colsample_bytree参数）

### 6.3 集成学习特点

- **Bagging vs Boosting**：
  - Bagging：并行训练，减少方差，适用于高方差模型（如深度决策树）
  - Boosting：顺序训练，减少偏差，适用于弱学习器
  - 训练方式：Bagging基学习器独立并行，Boosting基学习器顺序依赖
  - 权重策略：Bagging等权重投票，Boosting根据性能加权

- **集成学习模型分类**：
  - 集成学习：Random Forest、GBDT、XGBoost、AdaBoost
  - 非集成学习：逻辑回归(LR)、SVM、朴素贝叶斯等

- **Stacking**：使用元学习器组合基学习器，分层训练
- **Voting**：
  - 硬投票：基于类别标签的多数投票
  - 软投票：基于预测概率的加权平均

- **多样性实现**：
  - Bagging：数据样本扰动（Bootstrap采样）
  - Random Forest：数据样本扰动 + 输入属性扰动（随机特征子集）
  - Boosting：样本权重调整

## 第七章 模型选择与优化

### 7.1 过拟合与欠拟合

- **过拟合**：
  - 表现：训练误差小，测试误差大
  - 原因：模型过复杂，训练数据不足
  - 解决：增加数据、正则化、简化模型、早停

- **欠拟合**：
  - 表现：训练误差大，测试误差大
  - 原因：模型过简单，特征不足
  - 解决：增加特征、提高模型复杂度、减少正则化

### 7.2 模型验证

- **交叉验证**：
  - k折交叉验证：将数据分k份，轮流做验证集
  - 作用：更可靠的模型评估，不能提高模型准确率
  - 结果：取k折平均值
  - 留一法：k=n，计算量大但无偏

- **网格搜索**：
  - **计算公式**：参数组合数 × 交叉验证折数
  - **计算例子**：
    - 我们使用网格搜索和交叉验证来优化某模型，搜索的参数有3个，每个参数给定5个搜索值，进行3折交叉验证，请问模型需要训练多少次？
      - $\text{参数组合数} = 5 \times 5 \times 5 = 125$
      - $\text{总训练次数} = \text{参数组合数} \times \text{交叉验证折数} = 125 \times 3 = 375$

- **随机搜索**：在参数空间随机采样，适用于高维参数空间

### 7.3 偏差-方差权衡

- **偏差（Bias）**：模型预测值与真实值的差异
- **方差（Variance）**：模型在不同训练集上的预测差异（例如 K 折验证的时候）
- **泛化误差**：模型在新数据上的预测误差
- **噪声（Noise）**：数据本身的不可约误差
- **总误差**：$Error = Bias^2 + Variance + Noise$
- **高偏差**：欠拟合，需增加特征或模型复杂度
- **高方差**：过拟合，需减少特征或增加正则化
- **权衡策略**：
  - **降低偏差**：增加特征、提高模型复杂度、减少正则化强度
  - **降低方差**：增加训练数据、降低模型复杂度、增加正则化、使用集成方法
  - **模型复杂度与误差关系**：复杂度增加时偏差↓方差↑，需找到最优平衡点

### 7.4 梯度下降优化

- **梯度下降类型**：
  - 批量梯度下降：内存需求最高，收敛稳定
  - 随机梯度下降：内存需求最低，收敛波动大
  - 小批量梯度下降：折中方案，实际常用
- **学习率调整**：
  - 固定学习率
  - 学习率衰减
  - 自适应学习率（Adam、RMSprop）

### 8.1 神经网络基础

## 第九章 隐马尔科夫模型（HMM）

### 9.1 HMM基本概念

**基本要素**：

- 状态集合 S
- 观测集合 O
- 状态转移概率矩阵A：$a_{ij} = P(q_{t+1} = S_j | q_t = S_i)$
- 观测概率矩阵B：$b_j(o_t) = P(o_t | q_t = S_j)$
- 初始状态概率π：$\pi_i = P(q_1 = S_i)$

**模型假设**：

- 马尔科夫假设：当前状态只依赖于前一个状态
- 观测独立假设：观测值只依赖于当前状态

### 9.2 HMM三个基本问题

#### 9.2.1 概率计算问题

给定模型参数λ=(A,B,π)和观测序列O，计算P(O|λ)

- **前向算法**：从左到右递推计算观测序列概率
- **后向算法**：从右到左递推计算，常与前向算法结合使用

#### 9.2.2 解码问题（预测问题）

给定模型参数λ和观测序列O，求最可能的状态序列Q

- **Viterbi算法**：动态规划算法，求解最优状态序列
- **考试重点**：HMM解码问题专门用Viterbi算法处理
- **问题类型**：给定模型参数λ=(A,B,π)和观测序列X，计算最可能的隐状态序列Y**预测问题**
- **算法选择**：专门使用Viterbi算法（不是前向、后向或Baum-Welch算法）
- **考试重点**：此类问题明确属于"预测问题"类别

#### 9.2.3 参数学习问题

给定观测序列，估计模型参数

- **Baum-Welch算法**：EM算法的HMM实现（无监督学习）
- **极大似然估计（MLE）**：监督学习方法

### 9.3 参数估计方法

#### 9.3.1 监督学习：极大似然估计

- **适用条件**：已知观察序列和状态序列
- **计算方法**：通过统计频次计算转移概率和发射概率
- **特点**：无需迭代，计算简单直接
- **考试重点**：当"已知观察序列和产生观察序列的状态序列"时，直接用极大似然估计

#### 9.3.2 无监督学习：EM算法

- **适用条件**：仅知观察序列，状态序列未知
- **算法**：用Baum-Welch算法（EM算法）
- **特点**：需要迭代优化参数，可能收敛到局部最优解
- **注意**：前向后向算法通常与EM算法结合使用，不单独用于参数估计

#### 9.3.3 方法选择策略

- **已知观察序列和状态序列**：直接用**极大似然估计**
- **仅知观察序列，状态序列未知**：用Baum-Welch算法（EM算法）

### 9.4 应用场景与实例

#### 9.4.1 自然语言处理

- **语音识别**：音素识别和语音合成
- **词性标注**：确定单词的词性
- **命名实体识别**：识别人名、地名等实体

#### 9.4.2 生物信息学

- **基因序列数据集**：DNA序列分析，预测编码区
- **蛋白质结构预测**：预测蛋白质的二级结构

#### 9.4.3 金融分析

- **股票市场数据集**：金融时间序列分析
- **市场状态识别**：识别牛市、熊市等市场状态

#### 9.4.4 其他应用

- **电影浏览数据集**：用户行为序列建模
- **考试答案**：以上所有选项都可以应用HMM模型

#### 9.4.5 考试要点总结

1. **问题类型识别**：
   - 给定X,A,B,π计算Y → 预测问题（解码问题）
   - 给定观测序列，求模型参数 → 参数学习问题
   - 给定模型参数和观测序列，求概率 → 概率计算问题

2. **算法选择**：
   - 解码问题 → Viterbi算法
   - 参数估计（已知状态） → 极大似然估计
   - 参数估计（未知状态） → EM算法/Baum-Welch算法

3. **应用判断**：时序数据、序列建模问题通常都适用HMM

## 第十章 关联规则挖掘与推荐系统

### 10.1 关联规则挖掘

#### 10.1.1 基本概念

- **支持度**：$Support(A \Rightarrow B) = P(A \cap B)$，项集在数据库中出现的频率
- **置信度**：$Confidence(A \Rightarrow B) = P(B|A) = \frac{P(A \cap B)}{P(A)}$
- **提升度**：$Lift(A \Rightarrow B) = \frac{Confidence(A \Rightarrow B)}{P(B)}$
- **计算例子**：
  - 10000个订单，购买三元牛奶6000个，购买伊利牛奶7500个，同时购买4000个
  - AB的支持度：$Support = \frac{4000}{10000} = 0.4$
  - A→B的置信度：$Confidence = \frac{4000}{6000} = 0.67$
  - A→B的提升度：$Lift = \frac{0.67}{0.75} = 0.89$

#### 10.1.2 Apriori算法

- **算法原理**：基于频繁项集的逐层搜索
- **核心思想**：如果一个项集是频繁的，那么它的所有子集也必须是频繁的
- **算法步骤**：
  1. 扫描数据库，生成候选1项集
  2. 计算候选1项集的支持度，保留满足最小支持度的项集
  3. 连接步骤2中保留的项集，生成候选2项集
  4. 计算候选2项集的支持度，保留满足最小支持度的项集
  5. 重复步骤3和4，直到无法生成候选k+1项集
- **计算例子**：
  - 规则A→B：同时购买A和B的顾客比例4/7，购买A的顾客中购买B的比例1/2
    - 支持度 = 4/7
    - 置信度 = 1/2

#### 10.1.3 应用场景

- **购物篮分析**：发现商品间的关联关系（如"啤酒与尿布"）
- **商品推荐**：基于关联规则推荐相关商品
- **市场营销**：制定促销策略和商品搭配方案
- **网页推荐**：发现网页间的链接关系

### 10.2 推荐系统

#### 10.2.1 协同过滤

**UserCF（基于用户的协同过滤）**：

- **原理**：基于用户相似性，"喜欢这个商品的用户还喜欢"
- **计算方法**：计算用户间的相似度，推荐相似用户喜欢的物品
- **适用场景**：
  - 用户数量相对较少
  - 用户兴趣变化较慢
  - 社交推荐场景

**ItemCF（基于物品的协同过滤）**：

- **原理**：基于物品相似性，"买了这个商品的用户还买了"
- **计算方法**：计算物品间的相似度，推荐与用户历史行为相似的物品
- **适用场景**：
  - 物品数量相对较少
  - 物品属性相对稳定
  - 电商推荐场景

**UserCF vs ItemCF 对比**：

| 维度 | UserCF | ItemCF |
|------|--------|--------|
| 推荐依据 | 相似用户的偏好 | 相似物品的关联 |
| 计算复杂度 | 用户数量影响 | 物品数量影响 |
| 实时性 | 用户行为变化敏感 | 物品关系相对稳定 |
| 新用户问题 | 冷启动困难 | 相对友好 |
| 新物品问题 | 相对友好 | 冷启动困难 |
| 推荐多样性 | 较高 | 较低 |

#### 10.2.2 其他推荐方法

**内容过滤**：

- **原理**：基于物品特征和用户偏好进行推荐
- **优点**：不依赖其他用户数据，可解释性强
- **缺点**：难以发现用户潜在兴趣，推荐多样性有限

**混合推荐**：

- **加权混合**：对不同算法结果进行加权组合
- **切换混合**：根据情况选择不同算法
- **分层混合**：先用一种算法筛选，再用另一种算法排序

#### 10.2.3 个性化推荐分类

**个性化推荐**：

- **猜你喜欢**：基于用户历史行为的个性化推荐
- **好友推荐**：基于社交关系的推荐
- **相关推荐**：基于当前浏览内容的推荐

## 第十一章 非线性模型与核方法

### 11.1 非线性模型识别

- **线性模型**：
  - 线性回归、逻辑回归
  - 朴素贝叶斯（特征独立假设）
  - 线性SVM
- **非线性模型**：
  - 决策树、随机森林
  - 核SVM、RBF网络
  - 神经网络、深度学习
  - KNN（局部非线性）
- **判断标准**：模型是否能拟合非线性决策边界

### 11.2 核方法

- **核技巧**：将低维非线性问题映射到高维线性问题
- **常用核函数**：
  - 多项式核：$K(x,y) = (x^T y + c)^d$，适合规则数据
  - RBF核：$K(x,y) = \exp(-\gamma||x-y||^2)$，适合复杂边界
  - 字符串核：适合文本数据
- **核矩阵**：必须满足正定性

## 复习要点总结

### 核心算法掌握

1. **分类算法**：决策树、朴素贝叶斯、逻辑回归、SVM、KNN
2. **回归算法**：线性回归、Ridge、Lasso
3. **聚类算法**：K-means、DBSCAN、GMM
4. **集成方法**：随机森林、AdaBoost、GBDT、XGBoost
5. **降维算法**：PCA、LDA

### 重要概念理解

1. **评估指标**：准确率、精确率、召回率、F1、ROC/AUC
2. **模型选择**：过拟合/欠拟合、交叉验证、偏差-方差权衡
3. **特征工程**：数据缩放、数据标准化、One-Hot编码、特征选择、特征提取
4. **模型优化**：梯度下降、正则化、早停
5. **数据预处理**：数据清洗、数据采样、特征缩放
6. **距离度量**：欧几里得距离、曼哈顿距离、余弦相似度

### 计算能力要求

1. **概率计算**：贝叶斯定理、条件概率
2. **距离计算**：各种距离度量的具体计算
3. **评估指标**：基于混淆矩阵的各种指标计算
4. **信息论**：熵、信息增益的计算
5. **特征工程**：归一化公式、分箱计算

### 应用场景判断

1. **监督 vs 无监督**：根据是否有标签数据
2. **分类 vs 回归**：根据目标变量类型,分类是离散的，回归是连续的
3. **算法选择**：根据数据特点和问题需求
4. **预处理需求**：根据算法特点决定是否需要归一化等操作
5. **大规模数据处理**：选择合适的处理策略

3. **参数影响**：理解超参数对模型性能的影响
4. **实际应用**：能够根据问题特点选择合适的算法
5. **优化策略**：掌握处理各种实际问题的方法
