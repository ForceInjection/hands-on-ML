# 机器学习考试复习提纲

## 第一章 机器学习基础概念

### 1.1 人工智能与机器学习关系

- **人工智能概念**：最早由图灵于1950年提出，并提出图灵测试模型
- **关系层次**：人工智能 > 机器学习 > 深度学习
- **误区澄清**：人工智能≠深度学习，机器学习是人工智能的实现手段
- **应用领域**：机器翻译、人脸识别、指纹识别等（VR不属于AI范畴）

### 1.2 机器学习基本概念

- **定义与特点**：可解决图像识别等问题，依赖统计学习
- **局限性**：目前无法完全代替人类
- **主要分类**：监督学习、无监督学习、强化学习

### 1.3 任务分类详解

#### 1.3.1 监督学习

- **定义**：使用有标签的训练数据进行学习
- **典型算法**：决策树、朴素贝叶斯、SVM、逻辑回归、KNN
- **应用场景**：分类（垃圾邮件检测）、回归（房价预测）

#### 1.3.2 无监督学习

- **定义**：从无标签数据中发现隐藏模式
- **典型算法**：K-means、DBSCAN、PCA、GMM
- **应用场景**：聚类、降维、异常检测

#### 1.3.3 强化学习

- **定义**：通过与环境交互获得奖励信号进行学习
- **核心要素**：状态、动作、奖励、策略
- **应用场景**：游戏AI、机器人控制、推荐系统

### 1.4 问题类型识别

- **分类问题**：预测离散标签（二分类/多分类）
- **回归问题**：预测连续数值
- **聚类问题**：将相似样本分组
- **关联规则挖掘**：发现数据项之间的关联关系

### 2.2 特征处理

#### 2.2.1 数值特征处理

- **归一化（Min-Max标准化）**：
  - 公式：$x_{norm} = \frac{x - x_{min}}{x_{max} - x_{min}}$
  - 映射到[0,1]区间
  - 保持原始分布形状

**计算例子**：

- 属性income：最小值12000，最大值98000
- 73600的归一化结果：$\frac{73600-12000}{98000-12000} = \frac{61600}{86000} = 0.716$

- **标准化（Z-score标准化）**：
  - 公式：$x_{std} = \frac{x - \mu}{\sigma}$
  - 均值0，方差1
  - 适用于正态分布数据

- **最小-最大规范化到指定区间**：
  - 公式：$x_{new} = \frac{(x - x_{min}) \times (new_{max} - new_{min})}{x_{max} - x_{min}} + new_{min}$

**计算例子**：

- 数据组：200,300,500,700,1000
- 规约到区间[5,10]，数据500的变换：
  - $x_{new} = \frac{(500-200) \times 5}{800} + 5 = \frac{300 \times 5}{800} + 5 = 6.875$

- **需要处理的算法**：逻辑回归、SVM、KNN、神经网络
- **不需要处理的算法**：决策树、随机森林、GBDT

- **特征分箱**：
  - 等宽分箱：$width = \frac{x_{max} - x_{min}}{n}$
  - 等频分箱：每箱样本数相等，每箱样本数 = 总样本数 / 箱数；
  - 卡方分箱：基于卡方统计量

**计算例子**：

数据：5, 10, 11, 13, 15, 35, 50, 55, 72, 92, 204, 215

**a) 等宽划分四个箱子**：
  
- 最小值：$\min = 5$
- 最大值：$\max = 215$
- 数据范围：$\text{range} = 215 - 5 = 210$
- 箱子宽度：$\text{width} = \frac{210}{4} = 52.5$

**4个箱子的划分**：

- 箱子1：$[5, 57.5)$ → 包含数据：5, 10, 11, 13, 15, 35, 50, 55
- 箱子2：$[57.5, 110)$ → 包含数据：72, 92
- 箱子3：$[110, 162.5)$ → 包含数据：无
- 箱子4：$[162.5, 215]$ → 包含数据：204, 215

**b) 等频划分四个箱子**：

- 数据总数：$n = 12$
- 每个箱子的数据个数：$\frac{12}{4} = 3$
- 按数值排序后，每3个数据分为一组

**4个箱子的划分**：

- 箱子1：$[5, 13]$ → 包含数据：5, 10, 11
- 箱子2：$(13, 50]$ → 包含数据：13, 15, 35
- 箱子3：$(50, 92]$ → 包含数据：50, 55, 72
- 箱子4：$(92, 215]$ → 包含数据：92, 204, 215

#### 2.2.2 类别特征处理

- **One-Hot编码**：
  - 适用于：颜色、品牌等无序类别特征
  - 不适用于：年龄等数值特征
  - 问题：高维稀疏、多重共线性
- **标签编码**：将类别映射为数字
- **目标编码**：用目标变量的统计量编码
- **二进制编码**：减少One-Hot编码的维度

#### 2.2.3 时间特征处理

- **时间格式转换**
  - **提取日期元素**：年、月、日、季度、星期等
  - **时间差特征**：距离某个重要时间点的天数
  - **周期性特征**：sin/cos变换处理周期性

### 2.3 距离度量

- **欧几里得距离**：$d = \sqrt{\sum_{i=1}^{n} (x_i - y_i)^2}$
- **曼哈顿距离**：$d = \sum_{i=1}^{n} |x_i - y_i|$

**计算例子**：

- 点A(2,-2)到B(-1,2)的曼哈顿距离：
  - $d = |2-(-1)| + |-2-2| = |3| + |-4| = 3 + 4 = 7$

- **余弦相似度**：$\cos(\theta) = \frac{A \cdot B}{||A|| \times ||B||}$

**计算例子**：

- 向量a=[1,2]，向量b=[4,5]
- $A \cdot B = 1 \times 4 + 2 \times 5 = 14$
- $||A|| = \sqrt{1^2 + 2^2} = \sqrt{5}$
- $||B|| = \sqrt{4^2 + 5^2} = \sqrt{41}$
- $\cos(\theta) = \frac{14}{\sqrt{5} \times \sqrt{41}} = \frac{14}{\sqrt{205}} \approx 0.978$

- **向量范数**：
  - L1范数：$||x||_1 = \sum_{i=1}^{n} |x_i|$
  - L2范数：$||x||_2 = \sqrt{\sum_{i=1}^{n} x_i^2}$
  - L∞范数：$||x||_{\infty} = \max_i |x_i|$

**计算例子**：

- 向量 A = [1, 3, 6, 4, -9, 0]
  - L1范数：$|1| + |3| + |6| + |4| + |-9| + |0| = 1 + 3 + 6 + 4 + 9 + 0 = 23$
  - L2范数：$\sqrt{1^2 + 3^2 + 6^2 + 4^2 + (-9)^2 + 0^2} = \sqrt{116} \approx 10.54$
  - L∞范数：$|1| + |3| + |6| + |4| + |-9| + |0| = 1 + 3 + 6 + 4 + 9 + 0 = 23$

### 2.4 特征选择

- **过滤法（Filter）**：
  - 方差选择法：移除低方差特征
  - 相关系数法：移除高相关特征

  - 互信息：衡量特征与目标的相关性
- **包装法（Wrapper）**：
  - 递归特征消除（RFE）
  - 前向选择、后向消除
- **嵌入法（Embedded）**：
  - L1正则化（Lasso）
  - 基于树的特征重要性

## 第三章 贝叶斯理论基础

### 3.1 贝叶斯定理

- **公式**：$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$
- **组成部分**：
  - $P(A|B)$：后验概率
  - $P(B|A)$：似然
  - $P(A)$：先验概率
  - $P(B)$：边际概率
- **应用场景**：医疗诊断、车祸责任判定、产品质检、垃圾邮件过滤

### 3.2 实际计算案例

#### 3.2.1 医疗诊断案例

- **问题设置**：
  - 疾病患病率：$P(D) = 0.01$
  - 检测敏感性：$P(+|D) = 0.95$
  - 检测特异性：$P(-|\neg D) = 0.95$
- **计算检测阳性时患病概率**：
  - $P(+) = P(+|D)P(D) + P(+|\neg D)P(\neg D)$
  - $P(+) = 0.95 \times 0.01 + 0.05 \times 0.99 = 0.0095 + 0.0495 = 0.059$
  - $P(D|+) = \frac{P(+|D)P(D)}{P(+)} = \frac{0.95 \times 0.01}{0.059} \approx 0.161$

#### 3.2.2 质量检测案例

- **问题设置**：
  - 合格品率：$P(G) = 0.95$
  - 检测准确率：$P(Pass|G) = 0.98$, $P(Fail|B) = 0.99$

## 第四章 监督学习

### 4.1 监督学习概述

- **定义**：有标签数据的学习方式
- **分类问题 vs 回归问题**
  - 分类：预测离散标签（如垃圾邮件检测、癌症诊断）
  - 回归：预测连续数值（如房价预测、点击量预测）

### 4.2 分类算法

#### 4.2.1 决策树

- **算法类型**：ID3、C4.5、CART
- **核心概念**：
  - 信息熵：$H(X) = -\sum_{i=1}^{n} p(x_i)\log_2(p(x_i))$
  - 信息增益：$IG(D,A) = H(D) - \sum_{v} \frac{|D^v|}{|D|} H(D^v)$
  - 信息增益率：$IGR(D,A) = \frac{IG(D,A)}{IV(A)}$，其中 $IV(A) = -\sum_{v} \frac{|D^v|}{|D|} \log_2 \frac{|D^v|}{|D|}$
  - 基尼指数：$Gini(D) = 1 - \sum_{k=1}^{|y|} p_k^2$

**计算例子**：

- 变量 [0,0,1,1,1] 的信息熵计算：
  - $p(0) = \frac{2}{5}$，$p(1) = \frac{3}{5}$
  - $H = -(\frac{3}{5} \log_2(\frac{3}{5}) + \frac{2}{5} \log_2(\frac{2}{5}))$

- **特点**：
  - ID3：只能处理分类问题，使用信息增益
  - C4.5：改进的ID3，可处理连续特征，使用信息增益率
  - CART：既可分类又可回归，使用基尼指数
- **父子节点关系**：一般情况下父节点熵更大（分割后不确定性降低）

#### 4.2.2 朴素贝叶斯

- **核心假设**：特征条件独立
- **贝叶斯定理应用**：$P(C|X) = \frac{P(X|C)P(C)}{P(X)}$
- **优缺点**：
  - 优点：算法简单，时空开销小，对缺失数据不敏感
  - 缺点：强独立性假设在实际中往往不成立
- **适用场景**：文本分类、垃圾邮件过滤

#### 4.2.3 逻辑回归

- **本质**：线性分类器，使用Sigmoid函数
- **Sigmoid函数**：$\sigma(z) = \frac{1}{1+e^{-z}}$
- **特点**：
  - 可解决二分类问题，也可扩展到多分类（One-vs-Rest）
  - 属于广义线性回归
- **多分类策略**：对于n类分类，需训练n个模型
- **优势**：输出概率值，可解释性强

#### 4.2.4 支持向量机（SVM）

- **核心思想**：寻找最优分离超平面，最大化间隔
- **核函数**：可与核函数结合处理非线性问题
  - 线性核：$K(x,y) = x^T \cdot y$
  - 多项式核：$K(x,y) = (x^T \cdot y + c)^d$
  - RBF核：$K(x,y) = \exp(-\gamma||x-y||^2)$
- **优缺点**：
  - 优点：泛化能力好，可结合核函数，调参效果好
  - 缺点：训练速度较慢，对大规模数据不友好
- **支持向量**：训练完成后只需保存支持向量即可分类

#### 4.2.5 K 近邻算法（KNN）

- **原理**：基于相似性进行分类
- **特点**：
  - 需保存所有训练样本（惰性学习）
  - 预测时需计算与所有训练样本的距离（线性搜索）
  - kdtree可优化搜索效率
- **距离度量**：欧几里得距离、曼哈顿距离、余弦距离
- **参数选择**：k值的选择影响模型复杂度

### 4.3 回归算法

#### 4.3.1 线性回归

- **模型形式**：$y = w_0 + w_1x_1 + w_2x_2 + \ldots + w_nx_n$
- **参数估计**：如单特征房价预测需要2个参数（斜率+截距）
- **求解方法**：
  - 最小二乘法：$\hat{w} = (X^TX)^{-1}X^Ty$，解析解，无局部最优问题
  - 梯度下降法：$w := w - \alpha \nabla J(w)$，需要设置学习率参数
- **假设条件**：线性关系、独立性、同方差性、正态性

#### 4.3.2 正则化回归

- **Ridge回归（L2正则化）**：
  - 损失函数：$J(w) = MSE + \lambda \sum_{i=1}^{n} w_i^2$
  - 特点：不适用于特征选择，参数趋向于0但不为0
- **Lasso回归（L1正则化）**：
  - 损失函数：$J(w) = MSE + \lambda \sum_{i=1}^{n} |w_i|$
  - 特点：适用于特征选择，可使部分参数为0
- **岭回归**：处理多重共线性问题
- **Elastic Net**：结合L1和L2正则化

### 4.4 模型评估

#### 4.4.1 分类问题评估

- **混淆矩阵**：TP、FP、TN、FN
- **评估指标**：
  - **准确率（Accuracy）**：$Accuracy = \frac{TP+TN}{TP+TN+FP+FN}$
  - **精确率（Precision）**：$Precision = \frac{TP}{TP+FP}$
  - **召回率（Recall）**：$Recall = \frac{TP}{TP+FN}$
  - **F1值**：$F1 = \frac{2 \times Precision \times Recall}{Precision + Recall}$
  - **特异性**：$Specificity = \frac{TN}{TN+FP}$

**计算例子**：

- 数据集：正样本100个，负样本100个
- 模型预测：预测为正样本80个（其中真正样本60个）
- 召回率计算：$Recall = \frac{60}{100} = 60\%$
- 精确率计算：$Precision = \frac{60}{80} = 75\%$

- **ROC曲线与AUC**：
  - ROC：FPR与TPR的关系曲线
  - AUC：ROC曲线下面积，取值范围[0,1]
  - AUC=0.5表示随机分类器
- **阈值调整影响**：
  - 提高阈值：精确率↑，召回率↓
  - 降低阈值：精确率↓，召回率↑

#### 4.4.2 回归问题评估

- **MSE**：$MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$，越小越好
- **MAE**：$MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$，越小越好，对异常值不敏感
- **RMSE**：$RMSE = \sqrt{MSE}$，越小越好，对异常值敏感
- **R²**：$R^2 = 1 - \frac{SS_{res}}{SS_{tot}}$，越大越好，取值范围(-∞,1]
- **MAPE**：$MAPE = \frac{1}{n} \sum_{i=1}^{n} \left|\frac{y_i - \hat{y}_i}{y_i}\right| \times 100\%$

## 第五章 无监督学习

### 5.1 聚类算法

#### 5.1.1 K-means算法

- **基本流程**：
  1. 指定聚类数k
  2. 随机选择初始聚类中心
  3. 分配样本到最近聚类中心
  4. 更新聚类中心：$\mu_k = \frac{1}{|C_k|} \sum_{x \in C_k} x$
  5. 重复直至收敛
- **目标函数**：$J = \sum_{k=1}^{K} \sum_{x \in C_k} ||x - \mu_k||^2$
- **特点**：
  - 无法自动确定聚类数量
  - 随机初始化导致结果可能不同
  - 适用于凸样本集
  - 对异常值敏感
- **评估指标**：SSE、轮廓系数、DB指数
- **优化方法**：K-means++初始化、肘部法则选择k值

#### 5.1.2 DBSCAN算法

- **特点**：基于密度的聚类，适用于非凸样本集
- **核心概念**：
  - 核心点：邻域内点数≥MinPts
  - 边界点：非核心点但在核心点邻域内
  - 噪声点：既非核心点也非边界点
- **参数**：ε（邻域半径）、MinPts（最小点数）
- **优势**：能发现任意形状的聚类，自动识别噪声点

#### 5.1.3 高斯混合模型（GMM）

- **基本思想**：假设数据由多个高斯分布混合而成
- **模型参数**：均值μ、协方差Σ、混合系数π
- **概率密度函数**：$p(x) = \sum_{k=1}^{K} \pi_k \mathcal{N}(x|\mu_k, \Sigma_k)$
- **EM算法**：
  - E步：计算后验概率 $\gamma_{nk} = \frac{\pi_k \mathcal{N}(x_n|\mu_k, \Sigma_k)}{\sum_{j=1}^{K} \pi_j \mathcal{N}(x_n|\mu_j, \Sigma_j)}$
  - M步：更新参数
- **与K-means对比**：
  - GMM：软聚类，给出概率
  - K-means：硬聚类，给出确定分配
- **优势**：可处理椭圆形聚类，提供不确定性度量

### 5.2 降维算法

#### 5.2.1 主成分分析（PCA）

- **目的**：降维、数据可视化、去噪
- **核心思想**：寻找数据方差最大的方向
- **数学原理**：
  - 协方差矩阵：$C = \frac{1}{n-1} X^T X$
  - 特征值分解：$C = Q\Lambda Q^T$
  - 主成分：特征向量对应的方向
- **特点**：
  - 无监督算法
  - 线性变换
  - 选择最大方差的主成分
  - 使用前需要标准化数据
- **应用**：等价于重建后均方误差最小
- **主成分选择**：累计方差贡献率≥85%

#### 5.2.2 线性判别分析（LDA）

- **目的**：有监督降维，最大化类间距离，最小化类内距离
- **目标函数**：$J(w) = \frac{w^T S_B w}{w^T S_W w}$
- **与PCA区别**：
  - PCA：无监督，最大化方差
  - LDA：有监督，最大化类别可分性

## 第六章 集成学习

### 6.1 Bagging方法

- **基本思想**：并行训练多个模型，投票决策
- **随机森林**：
  - 基于决策树的Bagging
  - 数据样本扰动实现多样性
  - 可用于分类和回归
  - 对异常值不敏感
  - 属性扰动和样本扰动并存
- **特点**：减少方差，防止过拟合

### 6.2 Boosting方法

- **基本思想**：顺序训练，后续模型关注前面模型的错误
- **AdaBoost**：
  - 弱分类器的线性组合：$H(x) = \text{sign}\left(\sum_{t=1}^{T} \alpha_t h_t(x)\right)$
  - 权重更新：$\alpha_t = \frac{1}{2} \ln\left(\frac{1-\epsilon_t}{\epsilon_t}\right)$
  - 样本权重更新：$D_{t+1}(i) = \frac{D_t(i)}{Z_t} \exp(-\alpha_t y_i h_t(x_i))$
  - 前向分步算法实现
  - 指数损失函数
  - 顺序训练（非独立训练）

- **GBDT（梯度提升决策树）**：
  - 只使用回归树
  - 对异常值敏感
  - 顺序训练
  - 拟合残差：$r_{mi} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$

- **XGBoost**：GBDT的优化版本
  - 支持并行计算
  - 正则化项
  - 处理缺失值

### 6.3 集成学习特点

- **Bagging vs Boosting**：
  - Bagging：并行训练，减少方差
  - Boosting：顺序训练，减少偏差
- **Stacking**：使用元学习器组合基学习器
- **Voting**：硬投票vs软投票

## 第七章 模型选择与优化

### 7.1 过拟合与欠拟合

- **过拟合**：
  - 表现：训练误差小，测试误差大
  - 原因：模型过复杂，训练数据不足
  - 解决：增加数据、正则化、简化模型、早停

- **欠拟合**：
  - 表现：训练误差大，测试误差大
  - 原因：模型过简单，特征不足
  - 解决：增加特征、提高模型复杂度、减少正则化

### 7.2 模型验证

- **交叉验证**：
  - k折交叉验证：将数据分k份，轮流做验证集
  - 作用：更可靠的模型评估，不能提高模型准确率
  - 结果：取k折平均值
  - 留一法：k=n，计算量大但无偏

- **网格搜索**：

**计算例子**（基于考试题目）：

- 3个参数×5个搜索值×3折交叉验证 = 3×5×3 = 45次训练
- 但题目答案是375，说明是 5×5×5×3 = 375次训练

- **随机搜索**：在参数空间随机采样

### 7.3 偏差-方差权衡

- **偏差（Bias）**：模型预测值与真实值的差异
- **方差（Variance）**：模型在不同训练集上的预测差异
- **噪声（Noise）**：数据本身的不可约误差
- **总误差**：$Error = Bias^2 + Variance + Noise$
- **高偏差**：欠拟合，需增加特征或模型复杂度
- **高方差**：过拟合，需减少特征或增加正则化

### 7.4 梯度下降优化

- **梯度下降类型**：
  - 批量梯度下降：内存需求最高，收敛稳定
  - 随机梯度下降：内存需求最低，收敛波动大
  - 小批量梯度下降：折中方案，实际常用
- **学习率调整**：
  - 固定学习率
  - 学习率衰减
  - 自适应学习率（Adam、RMSprop）

## 第八章 深度学习基础

### 8.1 神经网络基础

- **基本结构**：输入层、隐藏层、输出层
- **激活函数**：
  - 可用：$\tanh(x)$、$\sin(x)$、$ReLU(x) = \max(0,x)$、$Sigmoid(x) = \frac{1}{1+e^{-x}}$
  - 不可用：线性函数如$y=2x$
  - 原因：线性函数无法表达非线性关系
- **常用激活函数特点**：
  - Sigmoid：输出(0,1)，存在梯度消失
  - Tanh：输出(-1,1)，零中心化
  - ReLU：解决梯度消失，计算简单
  - Leaky ReLU：解决ReLU死神经元问题

### 8.2 损失函数与优化

- **损失函数**：
  - 回归问题：MSE、MAE、Huber Loss
  - 分类问题：交叉熵、Hinge Loss
- **反向传播**：基于链式法则计算梯度
- **优化算法**：SGD、Adam、RMSprop、AdaGrad

### 8.3 正则化技术

- **Dropout**：随机丢弃神经元，防止过拟合
- **Batch Normalization**：批量归一化，加速训练
- **Early Stopping**：早停，防止过拟合
- **权重衰减**：L1/L2正则化

## 第九章 特殊算法与应用

### 9.1 隐马尔科夫模型（HMM）

**基本要素**：

- 状态集合S
- 观测集合O
- 状态转移概率矩阵A：$a_{ij} = P(q_{t+1} = S_j | q_t = S_i)$
- 观测概率矩阵B：$b_j(o_t) = P(o_t | q_t = S_j)$
- 初始状态概率π：$\pi_i = P(q_1 = S_i)$

**三个基本问题及对应算法**：

1. **概率计算问题**：给定模型参数λ=(A,B,π)和观测序列O，计算P(O|λ)
   - **前向算法**：从左到右递推计算观测序列概率
   - **后向算法**：从右到左递推计算，常与前向算法结合使用

2. **解码问题（预测问题）**：给定模型参数λ和观测序列O，求最可能的状态序列Q
   - **Viterbi算法**：动态规划算法，求解最优状态序列
   - **考试重点**：HMM解码问题专门用Viterbi算法处理
   - **问题类型**：给定X,A,B,π计算Y属于**预测问题**

3. **参数学习问题**：给定观测序列，估计模型参数
   - **Baum-Welch算法**：EM算法的HMM实现（无监督学习）
   - **极大似然估计（MLE）**：监督学习方法

**参数估计方法选择**：

- **已知观察序列和状态序列**：直接用**极大似然估计**
  - 通过统计频次计算转移概率和发射概率
  - 无需迭代，计算简单直接
- **仅知观察序列，状态序列未知**：用Baum-Welch算法（EM算法）
  - 需要迭代优化参数
  - 可能收敛到局部最优解

**HMM应用场景**：

- **基因序列数据集**：DNA序列分析，预测编码区
- **电影浏览数据集**：用户行为序列建模
- **股票市场数据集**：金融时间序列分析
- **语音识别**：音素识别和语音合成
- **自然语言处理**：词性标注、命名实体识别
- **考试答案**：以上所有选项都可以应用HMM模型

**要点总结**：

1. **解码问题算法**：Viterbi算法（不是前向、后向或Baum-Welch）
2. **应用场景判断**：基因序列、电影浏览、股票市场等时序数据都适用
3. **问题类型识别**：给定参数求状态序列属于预测问题（解码问题）
4. **参数估计选择**：已知状态序列时用极大似然估计，未知时用EM算法

### 9.2 关联规则挖掘

- **基本概念**：
  - **支持度**：$Support(A \Rightarrow B) = P(A \cap B)$，项集在数据库中出现的频率
  - **置信度**：$Confidence(A \Rightarrow B) = P(B|A) = \frac{P(A \cap B)}{P(A)}$
  - **提升度**：$Lift(A \Rightarrow B) = \frac{Confidence(A \Rightarrow B)}{P(B)}$

**计算例子**：

- 10000个订单，购买三元牛奶6000个，购买伊利牛奶7500个，同时购买4000个
- AB的支持度：$Support = \frac{4000}{10000} = 0.4$

- **算法**：
  - Apriori算法：基于频繁项集的逐层搜索
  - FP-Growth：基于FP树的高效算法
- **应用**：购物篮分析（啤酒与尿布关系）、网页推荐
- **频繁项集**：挖掘频繁出现的商品组合

**计算例子**：参考《使用 Apriori 算法进行关联分析：原理与示例》一文。
  
- **Apriori算法步骤**：
    1. 扫描数据库，生成候选1项集
    2. 计算候选1项集的支持度，保留满足最小支持度的项集
    3. 连接步骤2中保留的项集，生成候选2项集
    4. 计算候选2项集的支持度，保留满足最小支持度的项集
    5. 重复步骤3和4，直到无法生成候选k+1项集

### 9.3 主成分分析（PCA）

- **基本思想**：降维、数据可视化、去噪
- **核心思想**：寻找数据方差最大的方向

### 9.3 推荐系统

- **协同过滤**：
  - UserCF：基于用户相似性，"喜欢这个商品的用户还喜欢"
  - ItemCF：基于物品相似性，"买了这个商品的用户还买了"
- **内容过滤**：基于物品特征和用户偏好
- **混合推荐**：结合多种推荐方法
- **个性化 vs 非个性化**：
  - 个性化：猜你喜欢、好友推荐
  - 非个性化：热榜、口碑榜
- **冷启动问题**：新用户、新物品的推荐

- **核技巧**：将低维非线性问题映射到高维线性问题
- **常用核函数**：
  - 多项式核：$K(x,y) = (x^T y + c)^d$，适合规则数据
  - RBF核：$K(x,y) = \exp(-\gamma||x-y||^2)$，适合复杂边界
  - 字符串核：适合文本数据
- **核矩阵**：必须满足正定性
