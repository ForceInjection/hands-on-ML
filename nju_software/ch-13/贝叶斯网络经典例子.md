# 雨？洒水器？从湿草坪反推原因的贝叶斯网络经典例子

这是机器学习教材中最经典、也最直观的例子之一。它模拟一个日常生活场景，涵盖多个变量之间的因果关系，非常适合作为学习贝叶斯网络的入门案例。

---

## 一、场景设定

你是一个喜欢早起的人，每天清晨都会查看家门前的草坪是否湿了。某天你发现草坪湿了，但你并不知道是因为**天上下雨**了，还是你家的**自动洒水器**夜里启动了。

这就引出了几个关键问题：

* 草坪湿是因为**下雨**，还是**洒水器**打开？
* 如果知道昨晚是**多云**的天气，这是否会增加下雨的可能性？
* 洒水器会不会因为天气原因（如下雨概率大）自动关闭？

---

## 二、变量定义

我们用四个布尔变量（取值为 True/False）来描述这个情景：

| 变量          | 含义       |
| ----------- | -------- |
| `Cloudy`    | 是否多云（天气） |
| `Rain`      | 是否下雨     |
| `Sprinkler` | 洒水器是否启动  |
| `WetGrass`  | 草坪是否湿了   |

---

## 三、贝叶斯网络结构图

四个变量之间的依赖关系如下图所示（箭头表示“因”影响“果”）：

```text
       Cloudy
       /     \
    Rain   Sprinkler
       \     /
       WetGrass
```

说明：

* `Cloudy` 影响 `Rain` 和 `Sprinkler`：天阴了更可能下雨，但洒水器可能因为天气不好而不开启；
* `Rain` 和 `Sprinkler` 决定 `WetGrass`：草坪湿的原因要么是雨，要么是洒水器，或者两者都发生。

---

## 四、条件概率建模

为了使用贝叶斯网络进行推理，我们需要给每个节点指定条件概率：

1. `P(Cloudy)`：多云的先验概率，例如 0.5
2. `P(Rain | Cloudy)`：在多云/非多云天气下，下雨的概率
3. `P(Sprinkler | Cloudy)`：在不同天气下，洒水器启动的概率
4. `P(WetGrass | Rain, Sprinkler)`：在不同组合下草坪湿的概率（共 4 种组合）

这些概率可以来自统计数据，也可以由专家经验提供。

---

## 五、推理任务示例（后验计算）

你早上看到草坪是湿的，想推测是否昨晚下过雨，即：

$$
P(Rain = \text{True} \mid WetGrass = \text{True})
$$

这类问题属于**后验推断**，也叫做**观测结果推因**，在贝叶斯网络中非常常见。

完整推理需要对所有可能组合进行边际化，可以使用**变量消元**或**贝叶斯定理**结合条件概率表来完成。

---

## 六、完整的数值建模与推理计算（教学示例）

### 6.1 定义变量与结构

我们复用前面定义的四个变量：

* `Cloudy`：是否多云（布尔变量）
* `Rain`：是否下雨，受 `Cloudy` 影响
* `Sprinkler`：洒水器是否启动，受 `Cloudy` 影响
* `WetGrass`：草坪是否湿，受 `Rain` 和 `Sprinkler` 共同影响

贝叶斯网络结构为：

```text
       Cloudy
       /     \
    Rain   Sprinkler
       \     /
     WetGrass
```

---

### 6.2 定义先验和条件概率表（CPT）

#### P(Cloudy)

| Cloudy | P   |
| ------ | --- |
| True   | 0.5 |
| False  | 0.5 |

#### P(Rain | Cloudy)

| Cloudy | Rain  | P   |
| ------ | ----- | --- |
| True   | True  | 0.8 |
| True   | False | 0.2 |
| False  | True  | 0.2 |
| False  | False | 0.8 |

#### P(Sprinkler | Cloudy)

| Cloudy | Sprinkler | P   |
| ------ | --------- | --- |
| True   | True      | 0.1 |
| True   | False     | 0.9 |
| False  | True      | 0.5 |
| False  | False     | 0.5 |

#### P(WetGrass | Rain, Sprinkler)

| Rain | Sprinkler | WetGrass | P    |
| ---- | --------- | -------- | ---- |
| T    | T         | T        | 0.99 |
| T    | T         | F        | 0.01 |
| T    | F         | T        | 0.90 |
| T    | F         | F        | 0.10 |
| F    | T         | T        | 0.90 |
| F    | T         | F        | 0.10 |
| F    | F         | T        | 0.00 |
| F    | F         | F        | 1.00 |

---

### 6.3 计算后验概率

**已知草坪湿，求下雨概率**:

$$
P(Rain = \text{True} \mid WetGrass = \text{True})
$$

根据贝叶斯公式：

$$
P(R=T \mid W=T) = \frac{P(R=T, W=T)}{P(W=T)}
$$

我们采用**枚举法**，对所有可能的变量组合进行求和。需要计算：

* 分子：所有 `Rain=T, WetGrass=T` 的情况概率之和；
* 分母：所有 `WetGrass=T` 的情况概率之和。

---

### 6.4 展开计算：枚举所有隐变量

我们固定 `WetGrass=True`，枚举所有 `Cloudy`、`Rain`、`Sprinkler` 的取值组合，共 8 种。

#### 所需联合概率形式

$$
P(C, R, S, W=T) = P(C) \cdot P(R \mid C) \cdot P(S \mid C) \cdot P(W=T \mid R, S)
$$

#### 建表计算

| Cloudy | Rain | Sprinkler | `P(C)` | `P(R｜C)` | `P(S｜C)` | `P(W=T｜R,S)` | 联合概率 `P(C,R,S,W=T)`                 |
| ------ | ---- | --------- | ------ | --------- | --------- | ------------- | ----------------------------------- |
| T      | T    | T         | 0.5    | 0.8       | 0.1       | 0.99          | 0.5 × 0.8 × 0.1 × 0.99 = **0.0396** |
| T      | T    | F         | 0.5    | 0.8       | 0.9       | 0.90          | 0.5 × 0.8 × 0.9 × 0.90 = **0.3240** |
| T      | F    | T         | 0.5    | 0.2       | 0.1       | 0.90          | 0.5 × 0.2 × 0.1 × 0.90 = **0.0090** |
| T      | F    | F         | 0.5    | 0.2       | 0.9       | 0.00          | 0.5 × 0.2 × 0.9 × 0.00 = **0.0000** |
| F      | T    | T         | 0.5    | 0.2       | 0.5       | 0.99          | 0.5 × 0.2 × 0.5 × 0.99 = **0.0495** |
| F      | T    | F         | 0.5    | 0.2       | 0.5       | 0.90          | 0.5 × 0.2 × 0.5 × 0.90 = **0.0450** |
| F      | F    | T         | 0.5    | 0.8       | 0.5       | 0.90          | 0.5 × 0.8 × 0.5 × 0.90 = **0.1800** |
| F      | F    | F         | 0.5    | 0.8       | 0.5       | 0.00          | 0.5 × 0.8 × 0.5 × 0.00 = **0.0000** |

---

### 6.5 汇总分子和分母

* **分子**：`Rain = T ∧ WetGrass = T` 的所有情况

  $$
  0.0396 + 0.3240 + 0.0495 + 0.0450 = \boxed{0.4581}
  $$

* **分母**：所有 `WetGrass = T` 的情况：

  $$
  0.0396 + 0.3240 + 0.0090 + 0.0495 + 0.0450 + 0.1800 = \boxed{0.6471}
  $$

---

### 6.6 计算后验概率

$$
P(R=T \mid W=T) = \frac{0.4581}{0.6471} \approx \boxed{0.708}
$$

---

### 6.7 结论与解释

观察到草坪湿了的情况下，有 **约 70.8% 的概率是因为下雨**。这个推理是基于：

* 多云天气更容易下雨；
* 洒水器有时在晴天会开启，但在多云天气可能不会；
* 下雨与洒水器均能独立引起草坪湿。
