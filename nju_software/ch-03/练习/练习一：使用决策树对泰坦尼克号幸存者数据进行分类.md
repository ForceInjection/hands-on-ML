# 练习一：使用决策树对泰坦尼克号幸存者数据进行分类

## 1. 任务说明

本课后习题要求你使用 `scikit-learn` 的决策树分类器，对泰坦尼克号乘客是否幸存（`Survived`）进行二分类建模，并完成一套可复现的评估与分析流程。

---

## 2. 数据来源与字段说明

### 2.1 数据来源

本习题默认使用 Kaggle 的 Titanic: Machine Learning from Disaster 数据集（训练集 `train.csv`、测试集 `test.csv`）。

### 2.2 字段说明（示例）

- 目标变量：`Survived`（0 表示未幸存，1 表示幸存）
- 常见特征字段：`Pclass`、`Sex`、`Age`、`SibSp`、`Parch`、`Fare`、`Embarked`
- 可能含大量缺失的字段：`Cabin`

---

## 3. 基础要求

请在实现中满足以下要求：

1. **数据清洗**：处理缺失值，并说明你为何选择该填充策略。
2. **特征处理**：对类别特征完成编码，并避免训练/测试的数据泄漏。
3. **模型训练**：训练一个基线决策树模型，并报告至少 3 个评估指标。
4. **模型改进**：通过超参数调优或剪枝策略改善泛化表现，并与基线模型对比。
5. **可解释性分析**：给出特征重要性或树结构（局部层级）的解读。

## 4. 分步练习

### 4.1 数据检查与清洗

1. 统计缺失值比例，并回答下列问题：
   - `Age`、`Fare`、`Embarked` 的缺失应如何处理？
   - `Cabin` 是否应该删除？请给出理由与替代方案（如提取是否有舱位信息的二值特征）。
2. 明确删除字段的原则，并给出你最终保留/删除的字段清单。

### 4.2 特征工程（选做与必做）

1. **必做**：构造 `FamilySize = SibSp + Parch + 1`，并评估其是否带来性能提升。
2. **选做**：构造 `IsAlone` 或从 `Name` 提取头衔特征（如 `Mr`、`Miss`、`Mrs`）。
3. 说明特征工程的依据：它对应怎样的业务假设或统计规律？

### 4.3 划分数据集与评估口径

1. 将训练集划分为训练集与验证集（建议使用分层抽样）。
2. 至少报告以下指标中的 3 个，并解释它们在本任务中的意义：
   - Accuracy
   - Precision / Recall
   - F1-score
   - ROC-AUC
3. 给出混淆矩阵，并解释主要错误类型。

### 4.4 基线模型训练

1. 训练一个基线决策树模型（只使用必要的预处理与默认超参数）。
2. 记录并报告验证集结果，作为后续对比基线。

### 4.5 模型改进：调参与剪枝

1. 使用 `GridSearchCV` 或 `RandomizedSearchCV` 搜索超参数，并给出搜索范围设置逻辑。
2. 至少覆盖以下参数中的 3 个：
   - `max_depth`
   - `min_samples_split`
   - `min_samples_leaf`
   - `criterion`
   - `ccp_alpha`
3. 说明你如何判断“过拟合”或“欠拟合”，并给出依据（例如训练/验证指标差异、树深度变化、学习曲线）。

### 4.6 可解释性分析

1. 输出并排序特征重要性，解释 Top-3 特征为何重要。
2. 若进行树结构可视化，请限制深度（例如只展示前 3 层），并解读关键分裂路径。
