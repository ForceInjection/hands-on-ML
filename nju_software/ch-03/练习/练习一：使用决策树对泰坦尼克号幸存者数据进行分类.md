# 练习一：机器学习全流程实战——泰坦尼克号生存预测

## 1. 任务说明

本练习旨在通过泰坦尼克号生存预测任务，帮助你熟悉 **Jupyter Notebook 的交互式开发模式**，掌握 **数据工程（Data Engineering）** 的核心步骤，并完整体验使用 `scikit-learn` 进行机器学习建模的标准流程。

你需要提交一个 `.ipynb` 文件，其中应包含完整的代码、运行结果以及必要的 Markdown 文本说明（如对数据的观察、模型选择的理由等）。

---

## 2. 数据来源与说明

### 2.1 数据来源

使用经典的 Kaggle Titanic 数据集。

### 2.2 字段说明

- **Survived**: 目标变量，0 = 未幸存，1 = 幸存
- **Pclass**: 船票等级 (1/2/3)
- **Sex**: 性别
- **Age**: 年龄
- **SibSp**: 泰坦尼克号上的兄弟姐妹/配偶数量
- **Parch**: 泰坦尼克号上的父母/子女数量
- **Ticket**: 船票号码
- **Fare**: 票价
- **Cabin**: 客舱号码
- **Embarked**: 登船港口 (C = Cherbourg, Q = Queenstown, S = Southampton)

## 3. 练习内容与要求

请按照以下步骤在 Notebook 中完成任务。**建议使用多个 Cell 分步骤编写代码，并在关键步骤前添加 Markdown Cell 进行说明。**

### 3.1 环境准备与数据加载 (10 分)

1. **导入库**：导入 `pandas`, `numpy`, `matplotlib`, `seaborn` 以及 `scikit-learn` 相关模块。
2. **加载数据**：读取 `train.csv` 和 `test.csv`。
3. **数据预览**：使用 `.head()`, `.info()`, `.describe()` 等方法观察数据结构、字段类型及缺失情况。

### 3.2 数据探索与可视化 (EDA) (20 分)

1. **缺失值分析**：统计各列缺失值的数量或比例，并用可视化图表（如柱状图或热力图）展示。
2. **特征分布**：
   - 分析数值型特征（如 `Age`, `Fare`）的分布。
   - 分析类别型特征（如 `Sex`, `Embarked`, `Pclass`）的分布。
3. **相关性分析**：探索特征与目标变量 `Survived` 之间的关系（例如：不同性别的幸存率有何差异？）。

### 3.3 数据工程 (Data Engineering) (30 分)

这是本次练习的重点。请至少完成以下操作：

1. **缺失值处理**：
   - `Age`：采用合理的方式填充（如均值、中位数，或根据 `Name` 中的称谓分组填充）。
   - `Embarked`：填充众数。
   - `Cabin`：缺失较多，可以考虑丢弃，或提取“是否有客舱信息”作为新特征。
2. **特征构造**：
   - 创建一个新特征 `FamilySize` (家庭规模 = SibSp + Parch + 1)。
   - (选做) 从 `Name` 中提取称谓 (Title) 作为新特征。
3. **特征编码**：
   - 将类别特征（如 `Sex`, `Embarked`）转换为数值形式。推荐使用 `OneHotEncoder` 或 `LabelEncoder`，也可以使用 `pandas.get_dummies`。
4. **特征选择**：确定最终进入模型的特征列表。

### 3.4 模型构建与评估 (30 分)

1. **数据集划分**：将处理好的训练数据划分为**训练集**和**验证集**（建议 8:2 划分，设置 `random_state` 保证可复现）。
2. **模型训练**：
   - 选择**任意两个**不同的分类模型进行训练（例如：逻辑回归 `LogisticRegression`、决策树 `DecisionTreeClassifier`、随机森林 `RandomForestClassifier` 或 KNN）。
   - 简要说明选择这些模型的原因。
3. **模型评估**：
   - 在验证集上计算并报告 **Accuracy (准确率)**。
   - (选做) 报告 Precision, Recall, F1-score 或绘制混淆矩阵。
4. **结果对比**：对比两个模型在验证集上的表现，选出表现更好的模型。

### 3.5 总结与思考 (10 分)

在 Notebook 的最后添加一个 Markdown 单元格，简要回答以下问题：

1. 在数据清洗过程中，你遇到的最大挑战是什么？是如何解决的？
2. 你认为哪个特征对预测结果影响最大？（可以结合可视化结果或模型特征重要性说明）
