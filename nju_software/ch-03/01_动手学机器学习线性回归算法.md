## 2. 算法概述

线性回归是一类用于回归任务的基础模型，目标是学习输入特征与连续目标之间的近似线性关系（Montgomery et al., 2012；Seber & Lee, 2003）。它既是统计建模中的经典方法，也是监督学习中常用的基线（baseline）模型（Hastie et al., 2009）。

从机器学习视角看，线性回归通常关注两个层面：

- **预测**：给定输入 $\boldsymbol{x}$，输出连续值 $\hat{y}$，并在未见数据上取得较小误差；
- **解释**：系数 $\boldsymbol{w}$ 的符号与大小反映特征与目标的线性关联方向与强度，但该解释依赖于数据分布、特征尺度与共线性等条件（Montgomery et al., 2012）。

常见使用场景包括：

- 价格或需求预测（如房价、销量、能耗）；
- 风险或强度估计（如评分、指标预测）；
- 作为更复杂模型的基线（baseline）进行效果对比；
- 作为正则化回归（Ridge、Lasso 等）的基础形式，便于进一步改进泛化能力（Hastie et al., 2009）。

从建模形式上看，只有一个输入变量称为简单线性回归，输入变量多于一个称为多元线性回归。

线性回归通常隐含如下建模假设或近似条件（用于保证模型合理性与推断结论的可用性）：关系近似线性、误差项均值为 0、方差相对稳定、样本之间近似独立等；当这些条件明显不满足时，应通过特征工程、正则化或更合适的模型进行改进（Montgomery et al., 2012）。

## 3. 算法原理

### 3.1 核心思想

线性回归通过一个线性函数对目标进行预测，并通过最小化损失函数学习参数。最常见的设定是**最小化均方误差**（Mean Squared Error, MSE），对应**最小二乘估计**（Ordinary Least Squares, OLS）。

### 3.2 模型表示

设样本特征向量为 $\boldsymbol{x}\in\mathbb{R}^d$，目标为 $y\in\mathbb{R}$，线性回归模型为：

$$
\hat{y} = \boldsymbol{w}^\top \boldsymbol{x} + b
$$

其中 $\boldsymbol{w}$ 为权重向量，$b$ 为偏置项。对 $m$ 个样本组成的矩阵 $\boldsymbol{X}\in\mathbb{R}^{m\times d}$，可写成向量形式：

$$
\hat{\boldsymbol{y}} = \boldsymbol{X}\boldsymbol{w} + b\boldsymbol{1}
$$

### 3.3 目标函数

以 **MSE** 为例，损失函数为：

$$
\text{MSE}(\boldsymbol{w},b)=\frac{1}{m}\sum_{i=1}^{m}\left(y^{(i)}-\left(\boldsymbol{w}^\top\boldsymbol{x}^{(i)}+b\right)\right)^2
$$

最小化该损失可得到参数估计。MSE 对大误差惩罚更重，因此对异常值通常较敏感。

### 3.4 实例推导：手工求解一元线性回归参数

为了直观理解线性回归“最小二乘”在做什么，本节给出一个可手算的示例。为便于计算，这里构造一个教学用的玩具数据集（非真实业务数据）。

**场景描述**：
我们希望仅用房屋面积 $x$（单位：平方英尺）预测房价 $y$（单位：美元），采用一元线性回归模型：

$$
\hat{y}=wx+b
$$

**数据集**（自构造）：

| 样本 | 面积 $x$ | 房价 $y$ |
| :--: | :------: | :------: |
|  1   |  1000    | 200000   |
|  2   |  1500    | 250000   |
|  3   |  2000    | 300000   |

**步骤 1：写出最小二乘目标**：

$$
\min_{w,b}\sum_{i=1}^{m}\left(y^{(i)}-(wx^{(i)}+b)\right)^2
$$

**步骤 2：使用一元线性回归的闭式解**：

令 $\bar{x}=\frac{1}{m}\sum_{i=1}^{m}x^{(i)}$，$\bar{y}=\frac{1}{m}\sum_{i=1}^{m}y^{(i)}$，则：

$$
w=\frac{\sum_{i=1}^{m}(x^{(i)}-\bar{x})(y^{(i)}-\bar{y})}{\sum_{i=1}^{m}(x^{(i)}-\bar{x})^2},\quad
b=\bar{y}-w\bar{x}
$$

对本例：$\bar{x}=1500$，$\bar{y}=250000$。

- 分子：$(1000-1500)(200000-250000)+(1500-1500)(250000-250000)+(2000-1500)(300000-250000)$
  $= (-500)(-50000)+0+(500)(50000)=50000000$
- 分母：$(1000-1500)^2+(1500-1500)^2+(2000-1500)^2=250000+0+250000=500000$

因此：

$$
w=\frac{50000000}{500000}=100,\quad
b=250000-100\times1500=100000
$$

**结论**：
得到 $\hat{y}=100x+100000$。例如当 $x=1800$ 时，预测价格 $\hat{y}=280000$。

### 3.5 参数求解方法

常见求解方式包括解析解与迭代法两类。

1. **最小二乘解析解（Normal Equation）**

   当将偏置并入特征（令 $x_0=1$）后，可写成：

   $$
   \hat{\boldsymbol{w}} = (\boldsymbol{X}^\top\boldsymbol{X})^{-1}\boldsymbol{X}^\top\boldsymbol{y}
   $$

   在数值计算中，实际实现通常使用更稳定的求解方式（如 QR 分解或 SVD），避免直接显式求逆导致的不稳定。

2. **梯度下降（Gradient Descent）**

   对损失函数求梯度并迭代更新：

   $$
   \boldsymbol{w}\leftarrow \boldsymbol{w}-\eta\frac{\partial \text{MSE}}{\partial \boldsymbol{w}},\quad
   b\leftarrow b-\eta\frac{\partial \text{MSE}}{\partial b}
   $$

   其中 $\eta$ 为学习率。梯度下降适合样本量或特征维度较大、难以直接使用解析解的场景。

### 3.6 算法复杂度分析

设样本数为 $m$，特征维度为 $d$：

1. **解析解（Normal Equation）**：通常需计算 $\boldsymbol{X}^\top\boldsymbol{X}$ 并求解线性方程组，时间复杂度可近似为 $O(md^2 + d^3)$。
2. **梯度下降**：每次迭代计算梯度的复杂度约为 $O(md)$，若迭代 $T$ 轮，总体约为 $O(Tmd)$。

空间复杂度主要由存储数据矩阵决定，约为 $O(md)$。

## 4. 算法优缺点

### 4.1 优点

1. **简单易解释**：系数方向与大小具有直观意义，便于解释与沟通。
1. **训练与推理高效**：在中小规模数据上训练快速，可作为强基线模型。
1. **可扩展性好**：可与特征工程、正则化、核方法等结合，形成更强模型。

### 4.2 缺点

1. **线性假设限制**：真实关系显著非线性时，模型偏差较大。
1. **异常值敏感**：在 MSE 下极端样本可能显著影响参数估计。
1. **共线性影响**：多重共线性会导致系数不稳定、可解释性变差。

## 5. 经典案例实战：房价预测

### 5.1 数据来源与任务定义

本案例使用同目录下的 `house_prices.csv`，字段包括 `sqft`（房屋面积，平方英尺）、`bedrooms`（卧室数量）与 `price`（房价，美元）。

数据来源：`house_prices.csv` 由同目录下的 [linear_regression.ipynb](file:///Users/wangtianqing/Project/study/hands-on-ML/nju_software/ch-03/linear_regression.ipynb) 通过固定随机种子（`np.random.seed(42)`）生成并保存，属于教学用合成数据集。

### 5.2 环境准备

下面代码导入本案例所需的依赖库（与 notebook 保持一致）。

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score
```

### 5.3 数据加载与预处理

下面代码完成数据加载、特征与标签拆分、特征标准化，以及训练集 / 测试集划分（测试集占比 20%）。

```python
data = pd.read_csv("house_prices.csv")

print("数据集前几行：")
print(data.head())

X = data[["sqft", "bedrooms"]]
y = data["price"]

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

X_train, X_test, y_train, y_test = train_test_split(
    X_scaled, y, test_size=0.2, random_state=42
)
```

### 5.4 模型训练与评估

下面代码训练线性回归模型，并输出参数与评估指标（MSE、$R^2$），同时绘制“实际价格 vs 预测价格”散点图用于直观检查拟合效果。

```python
model = LinearRegression()
model.fit(X_train, y_train)

y_pred = model.predict(X_test)

print("模型参数：")
print("截距 (theta0): {:.2f}".format(model.intercept_))
print("标准化后的系数 (theta1, theta2): {}".format(model.coef_))

mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)
print("\n模型评估：")
print("均方误差 (MSE): {:.2f}".format(mse))
print("决定系数 (R^2): {:.2f}".format(r2))

plt.scatter(y_test, y_pred)
plt.xlabel("实际价格")
plt.ylabel("预测价格")
plt.title("实际价格 vs 预测价格")
plt.plot(y_test, y_test, color="red", linewidth=2)
plt.grid()
plt.show()
```

需要注意：由于特征经过标准化，输出的系数对应“标准化后的特征空间”，其数值大小不应直接解读为“每增加 1 平方英尺带来多少美元”的边际效应；若需要在原始量纲下解释系数，应在未标准化特征上拟合，或进行系数反标准化换算。

### 5.5 新样本预测

下面代码使用训练好的模型对“面积 2000 平方英尺、3 个卧室”的新房子进行预测（与 notebook 保持一致）。

```python
new_house = pd.DataFrame([[2000, 3]], columns=["sqft", "bedrooms"])
new_house_scaled = scaler.transform(new_house)

predicted_price = model.predict(new_house_scaled)
print("\n新房子预测价格：${:.2f}".format(predicted_price[0]))
```

## 6. 算法优化策略

### 6.1 特征工程

当线性关系不足以拟合数据时，可通过构造交互项或多项式特征提升表达能力，例如使用 `PolynomialFeatures` 生成二次项与交互项。

### 6.2 正则化

当存在多重共线性或特征维度较高时，正则化能够提升泛化能力与系数稳定性：

- Ridge（L2 正则化）：缓解共线性，降低方差；
- Lasso（L1 正则化）：在一定条件下产生稀疏解，实现特征选择；
- Elastic Net：结合 L1 与 L2，适用于相关特征成组出现的场景。

### 6.3 异常值与鲁棒回归

若数据中存在明显异常值，OLS 可能被极端样本主导。可考虑使用更鲁棒的回归方法（如 Huber 或 RANSAC），或在数据层面进行异常值检测与处理。

## 8. 总结

线性回归是回归问题中最基础、最重要的模型之一。它通过线性函数与最小化损失的方式学习参数，具有良好的可解释性与工程实用性。在线性假设不足或数据存在共线性、异常值等问题时，可以通过特征工程、正则化与鲁棒方法提升模型效果与稳定性。

## 10. 练习题参考答案

1. **特征高度相关时的系数不稳定与正则化缓解**：
   - **不稳定现象**：系数对样本微小扰动非常敏感；系数的符号可能翻转；系数绝对值可能被放大；系数标准误增大、置信区间变宽，导致显著性判断不可靠。
   - **原因直观解释**：当特征强相关（多重共线性）时，设计矩阵 \(X^\top X\) 条件数变差、接近奇异，使得最小二乘解的方差变大。
   - **正则化如何缓解**：
     - Ridge（L2）通过加入 \(\lambda\lVert w\rVert_2^2\)，等价于求解时对 \(X^\top X\) 加上 \(\lambda I\)，改善条件数并收缩系数，从而提升稳定性。
     - Lasso（L1）与 Elastic Net 也会收缩系数，且可能产生稀疏解；Elastic Net 在“相关特征成组出现”时通常更稳定。
2. **残差非对称或厚尾时的损失选择**：
   - **MSE 的局限**：MSE 对异常值非常敏感，隐含噪声近似高斯且关注均值的假设；当残差明显厚尾或包含离群点时，MSE 往往会被少数极端样本主导。
   - **替代损失**：
     - MAE（L1 损失）：对离群点更鲁棒，但在 0 点不可导（实现中通常使用次梯度或平滑近似）。
     - Huber 损失：小残差用二次、大残差用一次，在可导性与鲁棒性之间折中。
     - 分位数回归（Pinball loss）：直接建模条件分位数，适合非对称残差或需要上下界预测的场景。
3. **高 \(R^2\) 是否意味着预测性能好**：
   - **不一定**：\(R^2\) 主要衡量样本内拟合优度，不能保证样本外泛化；在特征很多、样本较少时，模型可能出现过拟合，导致测试集误差仍然很大。
   - **常见误导情形**：仅在训练集上计算 \(R^2\)；存在数据泄漏；目标方差很小或数据分布漂移使 \(R^2\) 可比性变差。
   - **更稳妥的做法**：在独立测试集或交叉验证上报告 MAE、RMSE 等误差指标，并结合残差诊断、学习曲线与正则化强度选择来评估模型的预测能力。
