## 2. 算法概述

### 2.1 什么是支持向量机

**支持向量机**（`Support Vector Machine`，简称 `SVM`）是一种监督学习算法，主要用于分类和回归任务。其核心思想是通过寻找一个**最优的超平面**，将不同类别的数据点尽可能宽地分开，这个超平面在高维空间中起到分类决策边界的作用。

![SVM](https://upload.wikimedia.org/wikipedia/commons/b/b5/Svm_separating_hyperplanes_%28SVG%29.svg)

在分类问题中，距离超平面最近的几个数据点被称为**支持向量**，它们对于确定超平面的位置和方向起着关键作用。`SVM` 通过最大化间隔的方式，提升了模型在未知数据上的泛化能力，尤其适用于数据维度较高但样本数量相对较少的情况。

### 2.2 数学基础铺垫

在深入理解 `SVM` 的原理之前，需要回顾一些相关的数学基础知识。

- **向量内积**：描述两个向量之间的关系，反映向量间的夹角大小。
- **向量范数**：衡量向量的长度，在 `SVM` 中用于表示数据点到超平面的距离。
- **凸优化**：`SVM` 的求解过程是一个典型的凸优化问题，具有唯一的全局最优解。
- **拉格朗日乘子法**：用于求解带约束优化问题的有效方法。

## 3. 算法原理

### 3.1 硬间隔最大化与线性可分 SVM

**硬间隔**最大化是针对线性可分问题提出的核心思想，其**目标**是在确保所有数据点都被正确分类的前提下，找到一个具有最大间隔的超平面。

形式化地，给定一个数据集 $D = \left\{ \left( \boldsymbol{x}_1, y_1 \right), \dots, \left( \boldsymbol{x}_m, y_m \right) \right\}$，其中 $y_i \in \{ -1, +1 \}$。我们希望找到参数 $\boldsymbol{w}$ 和 $b$，使得：

$$
y_i \left( \boldsymbol{w}^\top \boldsymbol{x}_i + b \right) \geq 1
$$

并最小化 $\frac{1}{2} || \boldsymbol{w} ||^2$（等价于最大化间隔 $\frac{2}{|| \boldsymbol{w} ||}$）。

### 3.2 软间隔最大化与非线性可分 SVM

在实际应用中，数据往往包含噪声或异常点，导致不可分。**软间隔**最大化通过引入松弛变量 $\xi_i \geq 0$，允许部分数据点违反约束。新的目标函数为：

$$
\min_{\boldsymbol{w}, b, \xi} \frac{1}{2} || \boldsymbol{w} ||^2 + C \sum_{i=1}^m \xi_i
$$

并满足约束：

$$
y_i(\boldsymbol{w}^\top \boldsymbol{x}_i + b) \ge 1 - \xi_i,\quad \xi_i \ge 0,\quad i=1,\dots,m
$$

其中，$C > 0$ 是惩罚参数。$C$ 越大，对误分类的惩罚越严厉；$C$ 越小，容忍度越高，模型泛化能力可能更强。

### 3.3 核函数与非线性 SVM

对于线性不可分的数据，`SVM` 引入**核函数**（`Kernel Function`），将数据映射到高维特征空间，使其变得线性可分。

常见核函数：

1. **线性核**：$K(\boldsymbol{x}_i, \boldsymbol{x}_j) = \boldsymbol{x}_i^\top \boldsymbol{x}_j$
2. **多项式核**：$K(\boldsymbol{x}_i, \boldsymbol{x}_j) = (\boldsymbol{x}_i^\top \boldsymbol{x}_j + c)^d$
3. **高斯核（RBF）**：$K(\boldsymbol{x}_i, \boldsymbol{x}_j) = \exp \left( - \frac{|| \boldsymbol{x}_i - \boldsymbol{x}_j ||^2}{2 \sigma^2} \right)$

在许多实现中也常写作 $K(\boldsymbol{x}_i, \boldsymbol{x}_j)=\exp(-\gamma \lVert \boldsymbol{x}_i-\boldsymbol{x}_j\rVert^2)$，其中 $\gamma=\frac{1}{2\sigma^2}$；在 `scikit-learn` 的 `SVC` 中，RBF 核的超参数使用 $\gamma$ 表示。

### 3.4 决策函数、支持向量与“稀疏性”

训练完成后，分类决策通常可以写成：

$$
f(\boldsymbol{x}) = \text{sign}\left(\sum_{i \in \mathcal{S}} \alpha_i y_i K(\boldsymbol{x}_i, \boldsymbol{x}) + b\right)
$$

其中，$\mathcal{S}$ 表示支持向量集合。直观理解：

- 只有一小部分样本（支持向量）会对最终决策边界产生直接影响，因此 `SVM` 具备一定的“稀疏性”。
- 非支持向量样本即使被移除，模型的决策边界通常也不会发生变化或变化很小。

### 3.5 训练与预测的复杂度（工程视角）

`SVM` 的训练复杂度与核函数、样本规模密切相关。以核 `SVM` 为例：

- **训练阶段**：通常需要处理核矩阵（大小约为 $n \times n$），当样本数 $n$ 较大时，时间与内存开销都会显著上升。实际实现多采用 SMO 等分解方法来提升可用性。
- **预测阶段**：一次预测的主要成本来自对支持向量求和，复杂度与支持向量数量 $|\mathcal{S}|$ 近似线性相关。

因此，经验上 `SVM` 更适合：样本量中小、特征维度较高、且边界较复杂的问题；若样本量非常大，可优先考虑线性模型、近似方法或分布式方案。

---

## 4. 算法优缺点

### 4.1 优点

- **高维空间有效**：在高维空间中仍能保持较好的分类效果。
- **间隔最大化倾向更稳健**：在相同训练误差水平下，更大的间隔通常对应更好的泛化表现。
- **决策函数具有稀疏性**：最终决策函数只由少数支持向量决定。

### 4.2 缺点

- **对缺失数据敏感**：需要完整的数据集。
- **大规模数据训练慢**：传统的 SMO 算法在海量数据上效率较低。
- **参数调节困难**：惩罚参数 $C$ 和核函数参数（如 $\gamma$）对模型性能影响巨大，需要仔细调优。

## 5. 经典案例实战：鸢尾花分类

### 5.1 环境准备与数据来源说明

本节以经典的 Iris（鸢尾花）数据集演示 `SVM` 分类流程。

- **数据来源**：Iris 数据集最早由 Fisher 提出（1936），后被整理收录于 UCI Machine Learning Repository，并被 `scikit-learn` 以内置数据集形式提供（`sklearn.datasets.load_iris`）。
- **可复现性说明**：下面代码固定 `random_state`，但不同的库版本与硬件环境可能造成轻微差异；在小数据集上，随机划分对结果波动也更明显。

### 5.2 数据探索与预处理（含可视化）

使用 `scikit-learn` 实现 `SVM` 分类任务。

```python
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np
import pandas as pd
from sklearn import datasets
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score, classification_report, ConfusionMatrixDisplay
from sklearn.decomposition import PCA
from matplotlib import rcParams

# 绘图风格设置（可选）
sns.set(style="whitegrid")

# 配置 matplotlib 字体（macOS 常见字体；如不生效可替换为本机可用字体）
rcParams['font.sans-serif'] = ['Heiti TC']
rcParams['axes.unicode_minus'] = False

# 1) 加载数据集
iris = datasets.load_iris()
X = iris.data
y = iris.target
target_names = iris.target_names

# 2) 数据集划分
# 提示：也可以加入 stratify=y，保证训练集/测试集类别比例与原始数据一致
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# 3) 特征分布可视化（使用训练集原始数据）
plt.figure(figsize=(12, 6))
df_train = pd.DataFrame(X_train, columns=iris.feature_names)
df_train["species"] = [target_names[label] for label in y_train]
melt_df = df_train.melt(id_vars="species", var_name="features", value_name="value")
plt.title("Feature Distributions by Species (Training Set)")
sns.boxplot(x="features", y="value", hue="species", data=melt_df)
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

# 4) 数据标准化（SVM 对尺度非常敏感）
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# 5) 模型训练
# kernel="rbf" 使用高斯核；gamma="scale" 为 scikit-learn 推荐默认策略
model = SVC(kernel="rbf", C=1.0, gamma="scale", random_state=42)
model.fit(X_train_scaled, y_train)
y_pred = model.predict(X_test_scaled)

# 6) 模型评估（文本指标）
print("Accuracy: {:.4f}".format(accuracy_score(y_test, y_pred)))
print("\nClassification Report:\n", classification_report(y_test, y_pred, target_names=target_names))

# 7) 可视化：混淆矩阵
plt.figure(figsize=(8, 6))
ConfusionMatrixDisplay.from_predictions(y_test, y_pred, display_labels=target_names, cmap="Blues")
plt.title("混淆矩阵")
plt.show()

# 8) 可视化：分类结果与决策边界（PCA 投影到 2D）
# 说明：为了方便在二维平面展示决策边界，我们使用 PCA 将数据降维到 2D，
# 并在降维后的数据上重新训练一个 SVM 模型用于可视化。
pca = PCA(n_components=2)
X_train_pca = pca.fit_transform(X_train_scaled)
X_test_pca = pca.transform(X_test_scaled)

# 在 PCA 降维后的数据上训练模型
model_pca = SVC(kernel="rbf", C=1.0, gamma="scale", random_state=42)
model_pca.fit(X_train_pca, y_train)

# 创建网格
x_min, x_max = X_test_pca[:, 0].min() - 1, X_test_pca[:, 0].max() + 1
y_min, y_max = X_test_pca[:, 1].min() - 1, X_test_pca[:, 1].max() + 1
xx, yy = np.meshgrid(np.arange(x_min, x_max, 0.02), np.arange(y_min, y_max, 0.02))

# 预测网格点类别
Z = model_pca.predict(np.c_[xx.ravel(), yy.ravel()])
Z = Z.reshape(xx.shape)

plt.figure(figsize=(10, 8))
plt.contourf(xx, yy, Z, alpha=0.3, cmap=plt.cm.Paired)
scatter = plt.scatter(
    X_test_pca[:, 0],
    X_test_pca[:, 1],
    c=y_test,
    edgecolors="k",
    cmap=plt.cm.Paired,
    s=80,
    label="True Labels",
)

# 标记错误分类点（如存在）
errors = np.where(y_pred != y_test)
# 注意：这里的 errors 是基于原始高维特征训练的模型的预测结果
if len(errors[0]) > 0:
    plt.scatter(
        X_test_pca[errors, 0],
        X_test_pca[errors, 1],
        s=150,
        edgecolors="red",
        facecolors="none",
        linewidths=2,
        label="Misclassified"
    )

plt.xlabel("First Principal Component")
plt.ylabel("Second Principal Component")
plt.title("Classification Results with Decision Boundaries (PCA Projection)")
plt.legend()
plt.colorbar(scatter, ticks=[0, 1, 2], label="Species")
plt.show()
```

### 5.3 结果指标解读（与 KNN 章节一致的口径）

通过 `Accuracy`、分类报告（Classification Report）和混淆矩阵（Confusion Matrix），可以从不同角度理解模型表现：

1. **混淆矩阵（Confusion Matrix）**：
   - 行表示真实类别，列表示预测类别。
   - 对角线上的数值表示预测正确的样本数；非对角线表示误分类。
2. **精确率（Precision）**：
   - 在“预测为某一类”的样本中，有多少是真的属于该类。
3. **召回率（Recall）**：
   - 在“真实属于某一类”的样本中，有多少被模型找出来了。
4. **F1-score**：
   - Precision 与 Recall 的调和平均数，适合综合衡量分类效果。

在 Iris 数据集上，`SVM` 往往能取得较高准确率。但需要注意：该结果受训练/测试划分、标准化方式与超参数影响。

## 6. 算法优化策略

### 6.1 数据标准化

`SVM` 试图最大化决策边界的间隔，距离的计算依赖于特征的尺度。如果特征之间的量纲差异较大，大尺度的特征将主导距离计算，导致模型性能下降。因此，在使用 `SVM` 之前，务必对数据进行**标准化**（Standardization）或归一化（Normalization）。

### 6.2 参数调优

`SVM` 的性能高度依赖于超参数的选择，通常使用**网格搜索**（Grid Search）配合交叉验证来寻找最佳组合：

- **C**：惩罚系数。$C$ 越大，模型越不允许误分类（易过拟合）；$C$ 越小，决策边界越平滑（易欠拟合）。
- **Kernel**：核函数选择。线性可分选 `linear`，不可分选 `rbf` 或 `poly`。
- **Gamma**（针对 RBF 核）：控制单个样本的影响范围。$\gamma$ 越大，影响范围越小（易过拟合）；$\gamma$ 越小，影响范围越大（平滑）。

下面给出一个可复用的 `GridSearchCV` 示例（以 `SVC` 为例）：

```python
from sklearn.model_selection import GridSearchCV
import joblib
# from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

# 1. 准备数据
# 由于 sklearn 版本兼容性问题，这里暂时不使用 Pipeline，而是直接使用已标准化的数据。
# 注意：这在理论上会引入轻微的数据泄漏（验证集参与了标准化参数计算），但在教学示例中差异可忽略。
# 在生产环境中，建议使用 Pipeline 以避免任何数据泄漏。

# 2. 定义参数网格
# 注意：没有使用 Pipeline，所以参数前缀不需要 'svc__'
param_grid = {
    "C": [0.1, 1, 10, 100],
    "gamma": ["scale", 0.1, 0.01, 0.001],
}

# 3. 执行网格搜索
# 直接对标准化后的训练集进行网格搜索
# 修复：使用 threading 后端避免容器环境中的多进程 pickle 版本不一致问题
with joblib.parallel_backend('threading'):
    search = GridSearchCV(
        estimator=SVC(kernel="rbf"),
        param_grid=param_grid,
        cv=5,
        n_jobs=2, 
    )
    search.fit(X_train_scaled, y_train)
    
# 4. 输出结果
print("最佳参数组合:", search.best_params_)
print("最佳交叉验证得分: {:.4f}".format(search.best_score_))

# 5. 使用最佳模型在测试集上评估
best_model = search.best_estimator_
# 注意：测试集也需要使用相同的 scaler 进行标准化（已在前面步骤完成：X_test_scaled）
test_acc = best_model.score(X_test_scaled, y_test)
print("测试集准确率: {:.4f}".format(test_acc))
```

### 6.3 类别不平衡与代价敏感

当类别分布不均衡时，可以优先考虑：

- 使用 `class_weight="balanced"` 或显式传入 `class_weight`，让模型对少数类错误付出更高代价。
- 结合合适的评估指标（如 macro-F1、PR-AUC），避免只看 Accuracy。

### 6.4 最大间隔原理可视化

为了更直观地理解 SVM 的核心概念——**最大间隔 (Max Margin)**，我们可以构建一个简单的线性可分数据集进行可视化。

```python
from sklearn.datasets import make_blobs

# 创建可线性分离的数据
X_blob, y_blob = make_blobs(n_samples=50, centers=2, random_state=6)

# 训练SVM模型 (使用线性核和大C值以模拟硬间隔)
model_linear = SVC(kernel='linear', C=1000)
model_linear.fit(X_blob, y_blob)

# 获取决策边界和间隔边界
w = model_linear.coef_[0]
a = -w[0] / w[1]
xx = np.linspace(X_blob[:, 0].min() - 1, X_blob[:, 0].max() + 1, 100)
yy_decision = a * xx - (model_linear.intercept_[0]) / w[1]

# 计算间隔边界 (margin boundaries)
# 决策边界: w.x + b = 0
# 间隔边界: w.x + b = 1 和 w.x + b = -1
margin = 1 / np.sqrt(np.sum(model_linear.coef_ ** 2))
yy_down = yy_decision - np.sqrt(1 + a ** 2) * margin
yy_up = yy_decision + np.sqrt(1 + a ** 2) * margin

# 绘图
plt.figure(figsize=(10, 6))
plt.scatter(X_blob[:, 0], X_blob[:, 1], c=y_blob, s=30, cmap=plt.cm.Paired)

# 绘制决策边界和间隔
plt.plot(xx, yy_decision, 'k-', label='Decision Boundary')
plt.plot(xx, yy_down, 'k--', label='Margin Boundary')
plt.plot(xx, yy_up, 'k--')

# 圈出支持向量
plt.scatter(model_linear.support_vectors_[:, 0], model_linear.support_vectors_[:, 1], s=100,
           linewidth=1.5, facecolors='none', edgecolors='g', label='Support Vectors')

plt.title('SVM Max Margin Principle Visualization')
plt.legend()
plt.axis('tight')
plt.show()

print("="*50)
print("SVM模型信息:")
print("="*50)
print("权重向量 w:", model_linear.coef_[0])
print("偏置项 b: {:.4f}".format(model_linear.intercept_[0]))
print("支持向量数量:", len(model_linear.support_vectors_))
print("最大间隔距离: {:.4f}".format(2 * margin))
print("分类准确率: {:.4f}".format(model_linear.score(X_blob, y_blob)))
```

## 7. 思考与扩展讨论

为了加深对 SVM 算法的理解，建议同学们思考以下问题并进行尝试：

1. **SVM 与逻辑回归的对比**：
   - **损失函数**：`SVM` 常用合页损失（Hinge loss）；逻辑回归常用交叉熵损失（log-loss）。
   - **优化目标**：`SVM` 倾向于最大化分类间隔；逻辑回归倾向于最大化条件概率（等价最小化 log-loss）。
   - **稀疏性**：核 `SVM` 的决策主要由支持向量决定；逻辑回归通常由全部样本共同决定参数。
   - **适用场景**：`SVM` 更适合中小样本、高维或边界复杂的任务；逻辑回归更适合大样本、需要概率输出或可解释系数的任务。
2. **多分类问题的处理**：
   - **一对多（OvR）**：训练 $K$ 个二分类器，每个分类器将第 $i$ 类与其余类区分；`LinearSVC` 默认使用该策略。
   - **一对一（OvO）**：任意两类训练一个二分类器，共 $K(K-1)/2$ 个分类器；`SVC` 默认使用该策略，最终通常用投票决定类别。
3. **调参与工程要点**：
   - 当 $C$ 非常大或非常小时，决策边界与泛化能力会如何变化？
   - 当 RBF 核的 $\gamma$ 非常大或非常小时，边界会发生什么变化？
   - 移除 `StandardScaler` 后，重新训练并比较 Accuracy 与混淆矩阵，解释差异来源。
   - 在相同数据集上对比 `kernel="linear"` 与 `kernel="rbf"` 的表现，并结合可视化解释原因。

`SVM` 是一种强大的分类器，特别适合处理中小型、复杂的高维数据集。通过最大间隔思想与核技巧，它能够有效处理非线性分类问题。在实际应用中，标准化、合理的评估指标选择、以及围绕 $C$、$\gamma$、核函数的系统化调参，是获得稳定高性能模型的关键。

## 10. 练习题参考答案

1. **超参数的极端情况**：
   - **当 \(C\) 非常大**：对误分类惩罚更强，模型倾向于尽量把训练样本分对，间隔可能变窄，决策边界更“贴合”训练数据，过拟合风险上升（尤其在存在噪声时）。
   - **当 \(C\) 非常小**：对误分类更宽容，更强调间隔最大化，边界更平滑，可能出现欠拟合；训练误差可能上升，但泛化有时更稳定。
   - **当 RBF 核的 \(\gamma\) 非常大**：单个样本影响范围很小，边界会变得非常弯曲、局部化，容易把噪声也拟合进去，过拟合风险显著上升。
   - **当 RBF 核的 \(\gamma\) 非常小**：单个样本影响范围很大，模型更平滑，边界复杂度下降，可能趋近于线性可分的效果，欠拟合风险上升。
2. **去掉标准化的影响**：
   - 若移除 `StandardScaler`，距离/内积会被量纲或数值范围更大的特征主导，从而影响间隔与核函数计算，导致支持向量选择与决策边界位置发生变化，常见结果是准确率下降或不稳定，混淆矩阵中某些类别误判增多。
3. **线性核与 RBF 核对比**：
   - `kernel="linear"` 学习线性超平面，训练与预测通常更快，可解释性更强，适合近似线性可分或高维稀疏特征场景。
   - `kernel="rbf"` 能表达非线性边界，适合边界复杂的数据，但需要通过 \(C\) 与 \(\gamma\) 控制复杂度；参数不当时更容易过拟合或欠拟合。
   - 在 Iris 这类数据上，setosa 往往线性可分较容易，而 versicolor 与 virginica 的分界更复杂，RBF 核通常更有机会获得更灵活的分界（具体以划分与调参结果为准）。
