# PCA vs. LDA 降维方法比较

## 对比表格

| 对比维度          | PCA（主成分分析）                          | LDA（线性判别分析）                        |
|-------------------|-------------------------------------------|-------------------------------------------|
| **目标**          | 最大化数据整体方差 | 最大化类间距离，最小化类内距离（判别能力） |
| **是否考虑类别信息** | 不考虑，是无监督方法 | 考虑类别标签，是有监督方法 |
| **保留信息的方式** | 保留投影后数据的最大方差信息 | 保留最能区分类别的信息 |
| **依赖分布假设**  | 不严格依赖分布，常用于高斯分布数据 | 假设数据服从各类相同协方差的高斯分布 |
| **本质方法**      | 寻找数据协方差矩阵的特征向量 | 基于类内散度矩阵 S_W 和类间散度矩阵 S_B 的广义特征分解 |
| **降维上限**      | 最多降到原始维度数量 | 最多降到类别数减一（C - 1）维 |
| **典型应用**      | 数据压缩、可视化 | 分类前的预处理、提高分类效果 |

---

## 共同点总结

1. **都可用于降维**：通过线性变换将高维数据映射到低维空间。
2. **都使用特征分解**：如协方差矩阵或散度矩阵的特征值分解或奇异值分解（SVD）。
3. **都常用于处理高维数据**：例如文本、图像、基因表达等。

---

## 不同点重点说明

- **监督与否是核心区别**：PCA 不利用任何标签信息，因此只关注数据的整体结构；LDA 使用标签信息，优化的是类别判别能力。
- **应用目的不同**：PCA 更适合在信息压缩或数据探索时使用，而 LDA 多用于预处理以提升后续分类算法性能。
- **降维维数限制不同**：PCA 的降维维数只受原始维度限制，而 LDA 的降维维数上限是类别数减一。
