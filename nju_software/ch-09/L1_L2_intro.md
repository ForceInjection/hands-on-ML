# 机器学习模型调优之 L1 与 L2 正则化解析

正则化是机器学习中防止模型过拟合的核心技术之一，而 **L1 正则化**和 **L2 正则化**是两种最常用的方法。

---

## 一、正则化是什么？为什么需要它？

### 1. 过拟合问题

机器学习模型的训练目标是让预测结果尽量贴合训练数据，但过度拟合训练数据会导致模型在未知数据（测试集）上表现差，这种现象称为**过拟合**。例如，模型可能记住了训练数据中的噪声而非真正的规律。

### 2. 正则化的作用

正则化通过在损失函数中添加一个额外项（**正则项**），限制模型的复杂度。其核心思想是：**在最小化预测误差的同时，让模型参数尽量小或稀疏**，从而降低模型对噪声的敏感性。

---

## 二、L1 正则化（Lasso 回归）

### 1. 数学表达式

`L1` 正则化的损失函数为：  
$$
J(\theta) = \text{原始损失函数} + \lambda \sum_{i=1}^n |\theta_i|
$$

其中 $\lambda$ 是正则化强度参数，$\theta_i$ 是模型参数。

### 2. 特点与原理

- **稀疏性**：`L1` 正则化会将部分参数压缩为零，相当于自动进行**特征选择**。例如，若数据有 `100` 个特征，`L1` 可能仅保留 `10` 个非零参数。
- **几何解释**：`L1` 的约束区域是一个菱形，最优解常出现在菱形的顶点（即某些参数为零）。
- **梯度特性**：`L1` 的梯度更新包含符号函数（如 $\text{sign}(\theta_i)$），当参数接近零时可能直接跨过零点，导致稀疏性。

### 3. 应用场景

- **高维数据**：特征数量远大于样本数量时，`L1` 可筛选出关键特征。
- **需要可解释性**：稀疏模型更容易解释，例如在医疗诊断中识别关键指标。


## 三、L2 正则化（岭回归）

### 1. 数学表达式

`L2` 正则化的损失函数为：  
$$
J(\theta) = \text{原始损失函数} + \lambda \sum_{i=1}^n \theta_i^2
$$

### 2. 特点与原理

- **平滑性**：L2 正则化会均匀缩小所有参数，但不会完全置零。例如，参数可能从 5.0 变为 2.0，而非直接变为 0。
- **几何解释**：L2 的约束区域是一个圆形，最优解位于圆内，所有参数被均匀压缩。
- **梯度特性**：L2 的梯度与参数值成正比（如 $2\lambda\theta_i$），更新过程更稳定。

### 3. 应用场景

- **共线性数据**：当特征之间存在高度相关性时（如房屋面积和房间数），L2 能稳定参数估计。
- **防止过拟合**：通用性强，适合大多数需要泛化能力的场景。


## 四、L1 与 L2 的对比

| **特性** | **L1 正则化** | **L2 正则化** |
|--------------------|-------------------------------|-------------------------------|
| **参数结果**       | 稀疏解（部分参数为零）         | 非稀疏解（参数接近零）         |
| **梯度更新**       | 包含符号函数，不连续           | 连续且平滑                     |
| **优化难度**       | 需特殊处理（如次梯度法）       | 可直接用梯度下降法             |
| **抗异常值能力**   | 较强（绝对值惩罚对异常值不敏感）| 较弱（平方惩罚放大异常值影响） |
| **适用场景**       | 特征选择、高维数据            | 共线性数据、通用模型调优       |

## 五、如何选择正则化方法？

### 1. 根据数据特点
- **特征数量多且冗余**：优先使用 L1，自动过滤无关特征。
- **特征相关性高**：选择 L2，避免参数不稳定。

### 2. 根据业务需求

- **需要解释模型**：L1 的稀疏性更易解释关键特征。
- **追求稳定预测**：L2 更适合平衡各特征的影响。

### 3. 调参技巧

- **正则化参数 $\lambda$**：通过网格搜索或交叉验证选择。$\lambda$ 过大会导致欠拟合，过小则无法抑制过拟合。
- **弹性网络（Elastic Net）**：结合 L1 和 L2，适合特征数远超样本数且部分特征相关的情况。

## 六、代码示例（Python）

### 1. L1 正则化（Lasso 回归）

```python
from sklearn.linear_model import Lasso
# 生成数据并训练
lasso = Lasso(alpha=0.1)  # alpha 对应 λ
lasso.fit(X_train, y_train)
# 查看稀疏参数
print("非零参数数量:", np.sum(lasso.coef_ != 0))
```

### 2. L2 正则化（岭回归）

```python
from sklearn.linear_model import Ridge
# 训练模型
ridge = Ridge(alpha=0.5)
ridge.fit(X_train, y_train)
# 查看参数分布
print("参数均值:", np.mean(ridge.coef_))
```

## 七、总结

`L1` 和 `L2` 正则化通过不同的方式限制模型复杂度，是解决过拟合问题的利器。**L1 适合特征选择，L2 适合通用调优**。实际应用中，建议先尝试 `L2`，若模型仍过拟合或需要简化结构，再考虑 `L1` 或弹性网络。最终选择需结合数据特点和业务目标，通过交叉验证确定最优参数。
