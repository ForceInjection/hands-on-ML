## 一、K-Means 算法概述

### 1.1 生活中的类比：物流中心选址

为了直观理解 K-Means 算法，我们可以将其类比为 **“物流中心选址问题”**：

- **场景**：假设你是一家快递公司的运营总监，需要在城市中建立 $K$ 个分拣中心，服务全城散落的数千个快递点（数据样本）。
- **目标**：让所有快递点到其所属分拣中心的距离总和最小，以节省运输成本。
- **策略**：
  1. **随机选址**：一开始，你在地图上随机插上 $K$ 面旗帜作为临时的分拣中心。
  2. **就近归类**：将每个快递点指派给离它最近的那面旗帜。
  3. **中心迁移**：根据刚才归好类的快递点，找到它们地理位置的中心点（平均经纬度），将旗帜移动到那里。
  4. **循环迭代**：重复“就近归类”和“中心迁移”这两个步骤，直到旗帜的位置不再发生明显变化。

最终，这 $K$ 个旗帜的位置就是最优的分拣中心，而每个旗帜覆盖的区域就是一个“簇”。K-Means 算法正是通过这种**“分配-更新”**的交替迭代，寻找数据的最佳聚类中心。

### 1.2 核心定义

**K-Means（K-均值）** 是一种基于划分的聚类算法。其核心思想是将数据集 $D = \{x_1, x_2, ..., x_n\}$ 划分为 $K$ 个互不相交的簇 $C = \{C_1, C_2, ..., C_K\}$，使得每个簇内的样本尽可能紧密，而簇间的样本尽可能分离。

算法用**质心（Centroid）** $\mu_i$ 来代表第 $i$ 个簇，通常 $\mu_i$ 是簇 $C_i$ 中所有样本的均值向量。

---

## 二、数学原理与推导

K-Means 算法的本质是一个**最优化问题**。我们需要找到一种划分方案，使得簇内样本与质心的相似度最高（距离最小）。

### 2.1 目标函数：误差平方和 (SSE)

我们使用**误差平方和（Sum of Squared Errors, SSE）** 作为目标函数（或称损失函数、畸变函数），它衡量了聚类结果的紧密程度。

$$
J(C) = \sum_{i=1}^{K} \sum_{x \in C_i} ||x - \mu_i||^2
$$

其中：

- $K$ 是簇的数量。
- $x$ 是簇 $C_i$ 中的样本点。
- $\mu_i$ 是簇 $C_i$ 的质心。
- $||x - \mu_i||$ 表示样本 $x$ 与质心 $\mu_i$ 之间的**欧氏距离**。

**算法目标**：最小化 $J(C)$。

### 2.2 求解过程的数学解释

由于直接求解 $J(C)$ 的全局最小值是一个 NP-hard 问题，K-Means 采用**期望最大化（EM）算法**的思想，通过启发式迭代寻找局部最优解：

1. **E 步（Expectation）—— 固定质心，优化划分**：
   在第 $t$ 次迭代中，对于每个样本 $x_p$，将其分配到最近的质心 $\mu_i^{(t)}$ 所在的簇：

   $$
   C_i^{(t+1)} = \left\{ x_p : ||x_p - \mu_i^{(t)}||^2 \le ||x_p - \mu_j^{(t)}||^2, \forall j \neq i \right\}
   $$

2. **M 步（Maximization）—— 固定划分，优化质心**：
   为了最小化目标函数，我们需要更新质心。对目标函数 $J$ 关于 $\mu_i$ 求偏导并令其为 0：
   $$
   \frac{\partial J}{\partial \mu_i} = -2 \sum_{x \in C_i} (x - \mu_i) = 0
   $$
   解得：
   $$
   \mu_i^{(t+1)} = \frac{1}{|C_i^{(t+1)}|} \sum_{x \in C_i^{(t+1)}} x
   $$
   这证明了**新的质心确实应该是簇内所有样本的均值**。

## 三、算法流程详解

K-Means 算法的具体执行流程清晰明了，主要包含以下四个步骤：

1. **初始化（Initialization）**：

   - 指定聚类簇数 $K$。
   - 随机从数据集中选取 $K$ 个样本点作为初始质心 $\mu_1, \mu_2, ..., \mu_K$。

2. **样本分配（Assignment）**：

   - 遍历数据集中的每个样本 $x_i$。
   - 计算 $x_i$ 到 $K$ 个质心的距离。
   - 将 $x_i$ 分配给距离最近的质心所对应的簇。

3. **质心更新（Update）**：

   - 对每个簇，计算其内部所有样本的均值。
   - 将该均值作为新的质心位置。

4. **收敛判断（Convergence）**：
   - 比较新旧质心的位置变化。
   - 如果质心位置不再变化（或变化小于阈值），或者达到预设的最大迭代次数，则算法终止；否则，返回步骤 2 继续迭代。

## 四、优缺点与优化策略

尽管 K-Means 简单高效，但在实际应用中也面临诸多挑战。我们需要客观认识其优缺点，并掌握相应的优化方法。

### 4.1 算法优缺点

| 维度           | 优点                                                                                | 缺点                                                                                                     |
| :------------- | :---------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------- |
| **原理与实现** | 原理简单，易于理解和实现；收敛速度快。                                              | **必须预设 K 值**，且 K 值的选择对结果影响巨大。                                                         |
| **计算效率**   | 时间复杂度为 $O(n \cdot K \cdot t)$（n 为样本数，t 为迭代次数），适合大规模数据集。 | 对**离群点（Outliers）**和**噪声**非常敏感，少量异常值可能拉偏质心。                                     |
| **数据适应性** | 聚类效果直观，结果具有很好的可解释性。                                              | 假设簇是**凸形（球状）**的，难以发现任意形状（如环形、长条形）的簇；受**初始值**影响大，易陷入局部最优。 |

### 4.2 算法优化

针对 K-Means 的缺陷，学术界和工业界提出了多种优化方案，其中最著名的是 **K-Means++**。

#### 4.2.1 K-Means++：优化初始质心

传统 K-Means 随机选择初始质心，如果运气不好（如选到了两个靠得很近的点），会导致收敛慢甚至结果差。K-Means++ 的核心思想是：**初始质心之间的距离应尽可能远**。

**选择步骤**：

1. 随机选取第一个质心 $\mu_1$。
2. 对于每个样本 $x$，计算其与当前已选出的最近质心的距离 $D(x)$。
3. 选择一个新的数据点作为新质心，选择的概率与 $D(x)^2$ 成正比（即距离越远，被选中的概率越大）。
4. 重复步骤 2-3，直到选出 $K$ 个质心。
5. 使用这 $K$ 个质心作为初始值，运行标准的 K-Means 算法。

#### 4.2.2 Mini-Batch K-Means：处理超大规模数据

当数据量达到百万级甚至更高时，计算所有样本的均值非常耗时。**Mini-Batch K-Means** 每次迭代仅随机抽取一小批（Batch）样本来更新质心。虽然精度略有下降，但训练速度能提升数倍，非常适合大数据场景。

## 五、Python 实战应用

本节我们将使用 Python 的 `scikit-learn` 库，对一个啤酒数据集进行聚类分析，演示从数据加载到结果解读的全过程。

> **完整代码**：本节的完整代码和详细运行结果可参考配套 Notebook [02_Kmeans_beer.ipynb](02_Kmeans_beer.ipynb)。

### 5.1 数据准备与预处理

我们使用包含**热量**（calories）、**钠含量**（sodium）、**酒精含量**（alcohol）和**成本**（cost）等特征的啤酒数据集。

> **注意**：聚类算法对特征的尺度非常敏感，因此**数据标准化**是必不可少的步骤。

```python
import pandas as pd
from sklearn.preprocessing import StandardScaler

# 1. 加载数据
# 假设数据格式为：name calories sodium alcohol cost
beer = pd.read_csv('data.txt', sep=' ')

# 2. 特征选择
X = beer[['calories', 'sodium', 'alcohol', 'cost']]

# 3. 数据标准化 (Z-Score Normalization)
# 将特征缩放到均值为0，方差为1，消除量纲影响
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```

### 5.2 确定最优 K 值

如何确定 K 值？常用的方法是**肘部法则（Elbow Method）**和**轮廓系数（Silhouette Score）**。这里演示轮廓系数法。

```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

scores = []
k_range = range(2, 10)

# 遍历不同的 K 值
for k in k_range:
    kmeans = KMeans(n_clusters=k, random_state=0).fit(X_scaled)
    score = silhouette_score(X_scaled, kmeans.labels_)
    scores.append(score)

# 绘制轮廓系数曲线
plt.figure(figsize=(10, 6))
plt.plot(k_range, scores, marker='o')
plt.title('Silhouette Score vs Number of Clusters')
plt.xlabel('Number of Clusters (K)')
plt.ylabel('Silhouette Score')
plt.grid(True)
plt.show()
```

_分析：观察曲线，选择轮廓系数最高的点对应的 K 值（例如 K=3）。_

### 5.3 模型训练与结果分析

假设我们确定 $K=3$，接下来进行聚类并分析结果。

```python
import numpy as np

# 1. 训练模型
kmeans = KMeans(n_clusters=3, random_state=0)
kmeans.fit(X_scaled)

# 2. 获取聚类标签
beer['cluster'] = kmeans.labels_

# 3. 分析各簇特征（查看质心）
# 为了便于理解，我们通常反归一化或直接查看原始数据的均值
cluster_means = beer.groupby('cluster')[['calories', 'sodium', 'alcohol', 'cost']].mean()
print("Cluster Centers (Mean Values):")
print(cluster_means)

# 4. 可视化（选取两个特征展示）
colors = np.array(['red', 'green', 'blue'])
plt.figure(figsize=(8, 6))
plt.scatter(beer['calories'], beer['alcohol'], c=colors[beer['cluster']], alpha=0.6)
plt.title('Beer Clusters: Calories vs Alcohol')
plt.xlabel('Calories')
plt.ylabel('Alcohol')
plt.show()
```

通过分析 `cluster_means`，我们可以赋予每个簇业务含义，例如：

- **簇 0**：低热量、低酒精（可能对应“轻啤”）。
- **簇 1**：高热量、高酒精（可能对应“精酿”或“烈性啤酒”）。
- **簇 2**：中等热量、高成本（可能对应“高端品牌”）。

## 六、精选习题

为了检验对 K-Means 算法流程的掌握程度，请尝试解决以下例题。

> **习题验证代码**：本习题的完整计算与验证过程可参考配套 Notebook [02_Kmeans_习题验证.ipynb](02_Kmeans_习题验证.ipynb)。

### 6.1 题目

已知二维平面上有 6 个点：$A(2, 1)$、$B(3, 5)$、$C(6, 4)$、$D(5, 6)$、$E(7, 3)$、$F(1, 3)$。

根据 K-Means 算法的主要步骤，假设 **K=3**，**初始质心**随机选取为 $A(2, 1)$、$C(6, 4)$、$E(7, 3)$，使用**欧氏距离**作为相似性判断，请问**最终收敛后**的聚类结果是（ ）

- A. 三个簇：{ A，F }； { B，D }； { C，E }
- B. 三个簇：{ A，F，B }； { D }； { C，E }
- C. 三个簇：{ A，F }； { B，D，C }； { E }
- D. 三个簇：{ A，F }； { B，C }； { D，E }

### 6.2 解析

**答案：A**。

我们需要进行多轮迭代，直到簇中心不再变化（算法收敛）。

#### 6.2.1 第一轮迭代

**步骤 1：分配样本（Assignment）**
计算各点到初始质心 $\mu_1=A(2,1), \mu_2=C(6,4), \mu_3=E(7,3)$ 的距离：

| 点         | 到 A ($d^2$) | 到 C ($d^2$) | 到 E ($d^2$) | 归属  |
| :--------- | :----------- | :----------- | :----------- | :---- |
| **B(3,5)** | $1^2+4^2=17$ | $3^2+1^2=10$ | $4^2+2^2=20$ | **C** |
| **D(5,6)** | $3^2+5^2=34$ | $1^2+2^2=5$  | $2^2+3^2=13$ | **C** |
| **F(1,3)** | $1^2+2^2=5$  | $5^2+1^2=26$ | $6^2+0^2=36$ | **A** |

- **分配结果**：
  - 簇 1: {A, F}
  - 簇 2: {C, B, D}
  - 簇 3: {E}

**步骤 2：更新质心（Update）**
计算新簇的均值作为新质心：

- $\mu_1' = \text{mean}(A, F) = (\frac{2+1}{2}, \frac{1+3}{2}) = (1.5, 2)$
- $\mu_2' = \text{mean}(B, C, D) = (\frac{3+6+5}{3}, \frac{5+4+6}{3}) = (4.67, 5)$
- $\mu_3' = \text{mean}(E) = (7, 3)$

#### 6.2.2 第二轮迭代

**步骤 1：分配样本**
计算各点到新质心 $\mu_1'(1.5, 2), \mu_2'(4.67, 5), \mu_3'(7, 3)$ 的距离：

| 点         | 到 $\mu_1'$ ($d^2$) | 到 $\mu_2'$ ($d^2$)       | 到 $\mu_3'$ ($d^2$) | 归属                 |
| :--------- | :------------------ | :------------------------ | :------------------ | :------------------- |
| **A(2,1)** | $0.5^2+1^2=1.25$    | $2.67^2+4^2 \approx 23$   | $5^2+2^2=29$        | **$\mu_1'$**         |
| **B(3,5)** | $1.5^2+3^2=11.25$   | $1.67^2+0^2 \approx 2.8$  | $4^2+2^2=20$        | **$\mu_2'$**         |
| **C(6,4)** | $4.5^2+2^2=24.25$   | $1.33^2+1^2 \approx 2.8$  | $1^2+1^2=2$         | **$\mu_3'$** (变动!) |
| **D(5,6)** | $3.5^2+4^2=28.25$   | $0.33^2+1^2 \approx 1.1$  | $2^2+3^2=13$        | **$\mu_2'$**         |
| **E(7,3)** | $5.5^2+1^2=31.25$   | $2.33^2+2^2 \approx 9.4$  | $0$                 | **$\mu_3'$**         |
| **F(1,3)** | $0.5^2+1^2=1.25$    | $3.67^2+2^2 \approx 17.5$ | $6^2+0^2=36$        | **$\mu_1'$**         |

- **分配结果**：
  - 簇 1: {A, F}
  - 簇 2: {B, D}
  - 簇 3: {C, E}

**步骤 2：更新质心**：

- $\mu_1'' = (1.5, 2)$ (不变)
- $\mu_2'' = \text{mean}(B, D) = (\frac{3+5}{2}, \frac{5+6}{2}) = (4, 5.5)$
- $\mu_3'' = \text{mean}(C, E) = (\frac{6+7}{2}, \frac{4+3}{2}) = (6.5, 3.5)$

#### 6.2.3 第三轮迭代

**步骤 1：分配样本**
计算各点到新质心 $\mu_1''(1.5, 2), \mu_2''(4, 5.5), \mu_3''(6.5, 3.5)$ 的距离：

| 点         | 到 $\mu_1''$ ($d^2$) | 到 $\mu_2''$ ($d^2$) | 到 $\mu_3''$ ($d^2$) | 归属          |
| :--------- | :------------------- | :------------------- | :------------------- | :------------ |
| **A(2,1)** | **1.25**             | $24.25$              | $26.5$               | **$\mu_1''$** |
| **B(3,5)** | $11.25$              | **1.25**             | $14.5$               | **$\mu_2''$** |
| **C(6,4)** | $24.25$              | $6.25$               | **0.5**              | **$\mu_3''$** |
| **D(5,6)** | $28.25$              | **1.25**             | $8.5$                | **$\mu_2''$** |
| **E(7,3)** | $31.25$              | $15.25$              | **0.5**              | **$\mu_3''$** |
| **F(1,3)** | **1.25**             | $15.25$              | $30.5$               | **$\mu_1''$** |

**观察**：
所有样本点的簇归属与上一轮完全一致，未发生任何变化。

**步骤 2：判断收敛**
由于簇分配结果稳定，质心位置将不再移动，**算法收敛**。

#### 6.2.4 最终结论

经过三轮迭代，最终聚类结果如下：

- **簇 1**: {A, F}
- **簇 2**: {B, D}
- **簇 3**: {C, E}

对应选项 **A**。
