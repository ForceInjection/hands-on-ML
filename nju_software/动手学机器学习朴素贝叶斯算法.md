# 动手学机器学习朴素贝叶斯算法

## 1. 引言

在机器学习领域，朴素贝叶斯算法以其简单高效而备受青睐，尤其适用于文本分类等场景。本文将深入探讨朴素贝叶斯算法的原理、数学推导，并通过实战案例帮助读者掌握其应用。

## 2. 背景

### 2.1 贝叶斯定理

贝叶斯定理是朴素贝叶斯算法的理论基础，它描述了在已知某些条件下，事件发生的概率。公式如下：

$$
P(Y | X) = \frac{P(X | Y) P(Y)}{P(X)}
$$

其中：

- $ P(Y | X) $ 是后验概率，即已知 $ X $ 发生后 $ Y $ 发生的概率；
- $ P(X | Y) $ 是似然，即已知 $ Y $ 发生后 $ X $ 出现的概率；
- $ P(Y) $ 是先验概率，即 $ Y $ 发生的概率；
- $ P(X) $ 是边缘概率，即 $ X $ 出现的概率。

### 2.1 计算示例

**问题**：某 AI 公司招聘工程师，8 名应聘者中有 5 名是 985 院校毕业的，另外 3 人不是。985 毕业生做对算法题的概率是 80%，非985毕业生做对率只有 30%。随机选中的小甲做对了题目，那么小甲是985院校毕业的概率是多少？

**解答**：
设：

- $ A $ 为事件“小甲是985院校毕业的”；
- $ B $ 为事件“小甲做对了题”。

根据贝叶斯定理：

$$
P(A | B) = \frac{P(B | A) P(A)}{P(B)}
$$

计算各项概率：

1. 先验概率 $ P(A) = \frac{5}{8} $，$ P(\neg A) = \frac{3}{8} $；
2. 似然概率 $ P(B | A) = 0.8 $，$ P(B | \neg A) = 0.3 $；
3. 全概率 $ P(B) = P(B | A) P(A) + P(B | \neg A) P(\neg A) = 0.8 \times \frac{5}{8} + 0.3 \times \frac{3}{8} = \frac{4.9}{8} = 0.6125 $。

代入公式：

$$
P(A | B) = \frac{0.8 \times \frac{5}{8}}{0.6125} = \frac{4}{4.9} \approx 0.8163
$$

**结论**：小甲是985院校毕业生的概率约为 **81.63%**。

## 朴素贝叶斯算法原理及数学推导

朴素贝叶斯算法基于贝叶斯定理，并假设特征之间条件独立。对于给定的输入 $ X = (X_1, X_2, ..., X_n) $，计算其属于每个类别 $ Y $ 的概率，并选择概率最大的类别作为预测结果：

$$
Y^* = \arg\max_{Y} P(Y | X_1, X_2, ..., X_n)
$$

根据贝叶斯定理和条件独立性假设：

$$
P(Y | X) \propto P(Y) \prod_{i=1}^{n} P(X_i | Y)
$$

### 训练阶段

1. **先验概率**：$ P(Y) = \frac{\text{类别 } Y \text{ 的样本数}}{\text{总样本数}} $；
2. **条件概率**：$ P(X_i | Y) = \frac{\text{类别 } Y \text{ 中特征 } X_i \text{ 出现的次数} + \alpha}{\text{类别 } Y \text{ 的样本数} + k\alpha} $，其中 $ \alpha $ 是拉普拉斯平滑参数，$ k $ 是特征的取值个数。

### 预测阶段

对于新样本 $ X = (X_1, X_2, ..., X_n) $，计算每个类别 $ Y $ 的概率：

$$
P(Y | X) = P(Y) \prod_{i=1}^{n} P(X_i | Y)
$$

选取最大概率的类别作为预测结果。

## 经典案例实战（鸢尾花分类）

### 实战代码

```python
import numpy as np
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix

# 加载鸢尾花数据集
iris = load_iris()
X = iris.data  # 特征矩阵
y = iris.target  # 目标标签

# 将数据集划分为训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 创建高斯朴素贝叶斯分类器
gnb = GaussianNB()

# 使用训练数据训练模型
gnb.fit(X_train, y_train)

# 使用测试数据进行预测
y_pred = gnb.predict(X_test)

# 计算预测准确率
accuracy = accuracy_score(y_test, y_pred)
print(f"模型准确率: {accuracy:.2f}")

# 输出分类报告
print("分类报告:")
print(classification_report(y_test, y_pred, target_names=iris.target_names))

# 输出混淆矩阵
print("混淆矩阵:")
print(confusion_matrix(y_test, y_pred))
```

## 总结

朴素贝叶斯算法基于贝叶斯定理和特征条件独立性假设，通过计算后验概率进行分类。尽管独立性假设在现实中可能不完全成立，但该算法在许多实际应用中仍能取得较好的效果，尤其在文本分类等任务中表现突出。
